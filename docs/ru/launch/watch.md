# Смотреть бой сети

[← Назад](README.md) · [Документация](../README.md) · [Запуск](run.md) · [English](../../en/launch/watch.md)

Настоящий бой, где нашей стороной (сторона 1) командует нейросеть, а стороной 2 — ИИ игры. Сеть
работает в помощнике (`tools/nn/companion/`) в контейнере обучения; игра и помощник общаются через
два файла ([bridge](../apps/bridge.md)). С необученной `random.pt` по умолчанию её приказы случайные, но они проходят
весь путь: игра → сеть → приказы → наши отряды.

## Запуск

Одна команда (Docker Desktop запущен, игра закрыта):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/launcher/watch.ps1
```

Что она делает:

1. Собирает арену, где нашей стороной командует сеть: `python -m tools.build nn-arena --own-ai net
   --speed 1` (обычная скорость, решение раз в секунду).
2. Запускает помощника в контейнере `snake-ai-trainer` (репозиторий в `/repo`, папка игры в
   `/game`). Его строки идут в то же окно: по строке на решение.
3. Проводит бой через [launch.ps1](run.md): честная нормальная сложность, настройки игрока
   возвращаются байт в байт, удаляются только наши файлы.
4. Бой кончается сам (победа стороны, 10 минут боя или застой). Игра остаётся открытой ещё 30 с,
   чтобы увидеть конец, или пока вы её не закроете. Закрыть игру раньше тоже можно.
5. Останавливает помощника, удаляет файлы обмена из папки игры, копирует журнал помощника в папку
   прогона.

Параметры:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-Speed 1\|3\|10\|20` | 1 | Скорость боя. Скрипт её держит: ускорение в игре возвращается назад |
| `-DecideMs` | 1000 | Время боя между решениями, мс (250–5000) |
| `-Checkpoint` | `build/nn-train/random.pt`, если есть | Веса сети (контрольная точка [обучения](../training/README.md)); без неё — свежая необученная сеть |
| `-Greedy` | нет | Самый вероятный приказ вместо случайного выбора: необученная сеть тогда обычно шлёт всех на одного врага |
| `-Arena` | `arena` | Именованная арена из `config/nn/arenas.json` |
| `-TimeoutModelSeconds` | 600 | Предел боя, с времени боя |
| `-LingerSeconds` | 30 | Сколько игра остаётся открытой после итога |
| `-NoBuild` | нет | Взять сборку `net`, которая уже лежит в `build/nn-arena/` |
| `-EnemyAi game\|ai_like\|net` | `game` | Враг — ИИ игры или скрипт симулятора в помощнике (сборка `--enemy-ai`; с `-NoBuild` берётся из сборки, несовпадение — ошибка); журнал скрипта — `companion_enemy.jsonl` ([bridge](../apps/bridge.md#враг-под-скриптом-симулятора)); `net` — сеть на стороне 2, только с `-Target human` |
| `-Skirmish game\|off` | `game` | Режим застрельщиков под мостами (сборка `--skirmish`; с `-NoBuild` берётся из сборки) ([bridge](../apps/bridge.md#режим-застрельщиков)) |
| `-Target nn-arena\|lord-duel\|human` | `nn-arena` | Чью сборку и папку прогонов брать; `lord-duel` ([дуэль лордов](../apps/entries.md#lord_duel)) — только с `-NoBuild`, журнал помощника — `build/lord-duel/companion/`; `human` — [человек против сети](run.md#человек-против-сети): только с `-NoBuild`, помощник отвечает только стороне 2 (`--no-own`) |
| `-Graphics` | `BAI_GRAPHICS` | Набор графики на этот запуск (`launch.ps1 -Graphics`: `ultra`, `low`, `lowigpu`, `human2k`) |

Быстрая проверка: `-Speed 20 -LingerSeconds 0`.

Набор из 8 боёв против `ai_like` вместо ИИ игры: `build/steps/watch_set8.ps1 -Ckpt build/v2/itN.pt -EnemyAi ai_like`.

## Что печатает помощник

```
move   61  t   60.0 s  think   4.0 ms  turn  10.8 ms  | hold 1 attack 5 withdraw 1 | lord attack spear_1, ...
```

Номер хода, время боя, время сети (`think`), время от того, как помощник увидел состояние, до
записанного ответа (`turn`), сколько отрядов получили каждый вид приказа, первые приказы.

## Результаты

`build/nn-arena/runs/<время>/`: как у любого прогона арены (`events.jsonl`, `status.json`,
`launch.json`) и ещё `companion.jsonl` — каждое решение помощника с приказами. В `events.jsonl`:
`nn_orders` (отданные приказы, ожидание ответа), `nn_miss` (нет ответа вовремя), в `result` —
счётчики `nn_*` ([bridge](../apps/bridge.md#события)).

## Проверка в игре

Прогон `20260930-204047`: ×20, арена 7 на 7 Империи, необученная сеть (`build/nn-train/random.pt`,
случайный выбор), нормальная сложность, настройки возвращены.

| Что | Итог |
|---|---|
| Решения | 261 за 260,6 с боя (29 с реального времени); ответ на все 261, пропусков нет, битых файлов нет |
| Файлы | каждый раз переименование (`nn_write_mode: renamed`): в Lua игры есть `os.rename` и `os.remove` |
| Время сети | медиана 4,8 мс (маленькая сеть, 4 потока процессора) |
| От записи состояния до отданных приказов | реальное время: медиана 37 мс, 90% ≤ 43 мс, наибольшее 122 мс |
| Отдано приказов | 1502 (повторно отдаются только изменившиеся) |
| Выполнены ли | у 674 из 679 приказов «идти» и «отойти» точка приказа по данным самой игры (`ordered_position`) — это точка сети (медиана разницы 0 м); наши отряды двигались в 77% замеров, каждый прошёл 360–730 м |
| Бой | победил ИИ игры (осталось 534 бойца против 375): случайные приказы не побеждают |
| Ошибки Lua | нет; игра закрыта, наш pack и файлы обмена удалены |

Один запуск (`20260930-203835`) уронил игру во время загрузки, до запуска нашего скрипта
(событий нет совсем; в отчёте о падении только код игры). Та же сборка в следующий раз прошла.
Причина неизвестна; помощник теперь, пока ничего не происходит (загрузка, меню), ищет файл 10 раз
в секунду, а не 200.

На обычной скорости ожидание ответа — это ход помощника (~10–20 мс) и до 100 мс, пока игра прочтёт
файл: с большим запасом внутри решения в 1 с. Отдельным прогоном на ×1 не замерено.
