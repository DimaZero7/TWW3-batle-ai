# Проверка сети в игре

[← Назад](README.md) · [Документация](../README.md) · [Смотреть бой сети](watch.md) · [English](../../en/launch/gate.md)

Одна команда: N настоящих боёв, где нашей стороной командует обученная сеть (контрольная точка), а
другой — ИИ игры на честной нормальной сложности. Армии — из [генератора армий](../training/armies.md)
на проверочных зёрнах, которых сеть при обучении не видела. Сеть по очереди атакует и обороняется.
Проверка пройдена: **4 боя, не меньше 3 побед**. Это быстрая проверка перед ночной
([готовность сети](../training/network.md#готовность)), а не она сама.

## Запуск

Docker Desktop запущен, игра закрыта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/launcher/gate.ps1 -Checkpoint build/nn-train/latest.pt
```

Что происходит в каждом бою:

1. `python -m tools.build nn-arena --own-ai net --army-seed <зерно> --own-role attack|defend --speed 20
   --timeout 3600` — бой из генератора, нашей стороной командует сеть
   ([сборка](build.md#параметры)). Файл боя пишется в `build/nn-arena/random_<зерно>.xml`,
   `scenarios/` не меняется.
2. [watch.ps1](watch.md) `-NoBuild -LingerSeconds 0`: помощник в контейнере с этой контрольной
   точкой, один бой на запуск игры через [launch.ps1](run.md) — нормальная сложность
   (`battle_difficulty 1`), настройки игрока возвращаются байт в байт, удаляются только наши файлы.
3. Если у боя нет итога (игра упала при загрузке и т. п.), тот же бой запускается ещё раз
   (`-Retries 1`).

В конце — `build/nn-gate/<время>/summary.json` и таблица. Код выхода: 0 — пройдена, 1 — нет,
2 — проверка остановилась (например, игра уже была открыта).

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-Checkpoint` | `build/nn-train/latest.pt` | Веса сети; путь внутри репозитория (контейнер видит его как `/repo`) |
| `-Battles` | 4 | Сколько боёв |
| `-Offset` | 0 | Пропустить столько боёв плана: другой набор боёв |
| `-Speed 1\|3\|10\|20` | 20 | Скорость боя |
| `-TimeoutModelSeconds` | 0 — как в симуляторе | Предел боя, с времени боя; 0 — `battle_limit_s` из `config/nn/sim.json` (3600) |
| `-DecideMs` | 1000 | Время боя между решениями сети, мс |
| `-Greedy` | нет | Самый вероятный приказ; по умолчанию приказы выбираются случайно, как в обучении и в проверке в симуляторе (`tools/nn/train/evaluate.py`) |
| `-Retries` | 1 | Повторы боя без итога |

Один бой из плана: `-Battles 1 -Offset 3` — четвёртый (самые большие армии).

## Какие бои

`tools/nn/gate.py`, `python -m tools.nn.gate plan --battles 4`:

- Зёрна — из блока проверки игры `1 000 900 000 … 1 000 999 999`: последние 100 000 из
  `EVAL_SEEDS` генератора. Обучение берёт `TRAIN_SEEDS`, эти бои сеть не видит. Нижнюю часть
  `EVAL_SEEDS` оставляем проверке в симуляторе.
- План идёт по блоку по порядку и берёт зёрна по размеру нашей армии (отряды без лорда): по очереди
  1–4, 5–9, 10–14, 15–19. Так и в коротком плане есть маленькие и большие армии.
- Роли чередуются: в боях 1, 3, … сеть атакует, в 2, 4, … обороняется.

Первые 4 боя:

| Бой | Зерно | Наша армия | Армия ИИ игры | Сеть |
|---|---|---|---|---|
| 1 | 1000900000 | Империя, лорд + 1 | Империя, лорд + 1 | атакует |
| 2 | 1000900002 | Скавены, лорд + 5 | Империя, лорд + 3 | обороняется |
| 3 | 1000900007 | Скавены, лорд + 10 | Скавены, лорд + 9 | атакует |
| 4 | 1000900008 | Империя, лорд + 18 | Скавены, лорд + 19 | обороняется |

Если по итогам этих боёв выбирать версию сети, они перестают быть независимой проверкой: для
финальной проверки берите другой набор (`-Offset`).

## Итог боя

Итог — событие `result` из игры (`src/entries/nn_arena.lua`):

| `status` | Кто победил |
|---|---|
| `completed` | сторона `winner` (1 — сеть, 2 — ИИ игры) |
| `timeout` | вышло время — защитник (правило игры: обороняющийся побеждает по времени) |
| `stalled` | 10 минут боя никто не получал урон — защитник, как если бы время вышло |
| `deadline`, `incomplete`, нет итога | итога нет, это не победа |

Бой не на нормальной сложности (`battle_difficulty` в `launch.json` не 1) не засчитывается.

## Что в итоге

`build/nn-gate/<время>/`:

| Файл | Что |
|---|---|
| `battles.json` | план и папка прогона каждого боя (`build/nn-arena/runs/<время>/`) |
| `summary.json` | победы, поражения, без итога, `passed`, `fair`, `preferences_restored` и строка на бой |

Строка боя: зерно, фракции и шаблоны армий, бюджет (B, бюджет и цена каждой стороны; скавенам 0,8 от Империи), отряды сторон (с лордом), роль, кто победил и
как, длительность боя, бойцы в начале и в конце, стоящие отряды, счётчики сети (`nn`: решения,
ответы, пропуски, отданные приказы, `keep`, битые файлы), ошибки Lua, сложность, возвращены ли
настройки.

Таблица:

```
 #       seed  factions   units   role  winner       how battle s    men left nn moves/miss/orders
 4 1000900008   EMP-SKV   19v20 defend game_ai completed    567.6    866/2996           568/0/4306
```

`units` — отряды с лордом, `men left` — бойцы сети / ИИ игры.
