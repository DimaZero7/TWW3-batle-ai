# Запуск боя и результаты

[Документация](../README.md) · [Сборка](build.md) · [English](../../en/launch/run.md)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/launcher/launch.ps1 -Target duel
```

Параметры: `-Target duel|arena|map-capture` (обязательный),
`-TimeoutSeconds` (по умолчанию 1200, включая загрузку игры),
`-KeepGameOpen` (не закрывать игру после завершения).

> **Статус:** launcher собран из проверенной логики исследовательских
> скриптов, но в этом проекте игру ещё не запускал. Первый запуск — проверка
> самого стенда.

## Что делает launcher

1. Читает `config/default.json` и `config/local.json`, находит игру.
2. Проверяет, что WH3 не запущена и в папке игры нет файлов прошлого запуска.
3. Проверяет зависимости (SHA-256), затем копирует их и наш pack в `data`,
   сверяет хэш установленного pack.
4. Пишет **собственный** список модов `tww3_bai_<цель>_mods.txt`.
   Пользовательский `used_mods.txt` не трогается.
5. Запускает `Warhammer3.exe game_startup_mode battle <сценарий>; <mods>;`
   и сохраняет PID.
6. Читает журнал событий, пока игра пишет, и выводит ключевые строки.
7. Ждёт завершения: `result` (дуэль, по числу боёв), `arena_complete`,
   `probe_done`. Останавливается на `error` / `probe_error` / `skipped`,
   выходе процесса, новом отчёте о падении или тайм-ауте.
8. Копирует результаты и закрывает **только свой** процесс (тот же PID,
   путь и время старта).
9. Удаляет свой pack, свой список модов и свои копии зависимостей — только если
   они не изменились.

## Результаты

`build/<цель>/runs/<ГГГГММДД-ччммсс>/`:

| Файл | Содержимое |
|---|---|
| `manifest.json` | Сборка, которая играла |
| `launch.json` | PID, время, аргументы, смещение журнала |
| `events.jsonl` | Новые события этого запуска |
| `status.json` | `completed` / `lua_error` / `timeout` / `process_exited` / `crash_report` и итог очистки |
| `tww3_bai_map_capture_*.{csv,xml,jsonl}` | Для `map-capture`: сетка, XML боя, события |

Журнал дуэли и арены в папке игры (`tww3_bai_events.jsonl`) общий и
дописывается; launcher копирует только новую часть. Файлы
`tww3_bai_pending.txt` и `tww3_bai_sequence.txt` — состояние серии дуэлей,
их не удаляем.

## Обязательные моды

По умолчанию игра запускается без сторонних модов. Чтобы подключить
**True Sight: Improved Line of Sight** (Workshop 3628832922), возьмите
пример из `config/local.example.json`. Launcher:

- берёт `true_sight.pack` из папки Workshop и сверяет SHA-256;
- копирует его в `data`, если там его нет; чужой отличающийся файл не перезаписывает;
- пишет его в список модов перед нашим pack;
- после запуска удаляет только свою копию.

Зафиксированная версия мода — [config/mod-dependencies.json](../../../config/mod-dependencies.json).
История решения — [исследование зависимостей](../research/launch/dependencies.md).

## Время

По замерам исследования: до первого `ready` около 83 с, повторная загрузка
боя после переигровки около 11 с, сам бой на ×20 — 7–8 с. Поэтому дуэль
играет серию боёв в одном процессе ([замеры](../research/launch/loading-times.md)).

## Ограничения

- Переигровка дуэли ищет текст подтверждения в **русском** интерфейсе игры.
  Для другого языка нужен свой текст в `src/entries/duel.lua` (`REMATCH_PROMPT`).
- Настройка графики перед запуском (в исследованиях — минимальное качество,
  размер отрядов Ultra) пока не перенесена: скрипт для неё отсутствовал в kit.
