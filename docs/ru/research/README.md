## Файлы архива

Папка [research/](../../../research/) в корне репозитория:

| Путь | Что там |
|---|---|
| `research/evidence/map/` | Полевые замеры карты: сетки, маски, объекты, мосты, броды, лес, уклоны |
| `research/evidence/map-data/` | Доказательства к отчётам выше: XML, JSONL, CSV, изображения |
| `research/evidence/maps/moorlands-route/` | Полный пакет Moorlands Route |
| `research/evidence/units/`, `units-catalog/` | Опыты с отрядами: состояние, дальность, команды, расстановка |
| `research/probes/` | Минимальные Lua-зонды состояния и дальности |
| `research/scripts/` | Исследовательские Python/Lua-скрипты и прежние запускатели |
| `research/scripts/legacy-lua/` | Исходные Lua-модули до переноса в `src/apps` |
| `research/kit-manifest.json` | Происхождение и SHA-256 каждого файла исходного набора |

**В Git лежат только изображения (`.png`, `.svg`) и описания (`.md`) из
`research/evidence`.** Сырые данные — сетки `.csv`/`.gz`, массивы `.npz`,
журналы `.jsonl`, сводки `.json`, XML опытов — хранятся только на локальном
диске (см. `.gitignore`). В документации они помечены как «локальный архив».
Их хэши сохранены в `research/kit-manifest.json`: копию архива можно проверить.
Собрать эти данные заново можно только запусками игры, поэтому держите
резервную копию папки.

Скрипты в `research/scripts` ссылаются на старую структуру (`src/`, `tools/`,
`.tools/`) и запускаются только после правки путей; рабочие версии — в `tools/`.
