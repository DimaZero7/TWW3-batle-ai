# Обязательный мод сборки

[← Назад](README.md) · [Инженерия](../../README.md) · English

**Правило проекта от 26.09.2026:** все новые бои проекта проходят с **True Sight: Improved Line of Sight**, Workshop **3628832922**, автор GunPawDa. Пользователь отменил прежнее требование ванильной сборки. Нужна полная версия, не Lite. Другие сторонние игровые моды не разрешены. Созданные проектом pack-файлы запуска, политик и телеметрии являются собственными тестовыми артефактами и разрешены. Нативный DLL/hook по-прежнему требует отдельного разрешения пользователя.

## Версия и известные факты

Профиль `true-sight-v1`: файл `true_sight.pack`, 1065 байт, SHA-256 `790c54d3600d2335c746c5093d30b33431182c3ba373152def4aa4d4186ac511`. Версию определяем по хешу, а не дате страницы Workshop. Мод уже скачан Steam. Его сторонний pack не распространяем в открытом репозитории.

В проверенном файле одна таблица `_kv_rules_tables`: девять значений `1.0`, без скриптов и дополнительных pack-зависимостей. Четыре параметра относятся к переходу в ближний бой, четыре — к геометрическим коэффициентам проверки дружественного огня, один — к доле перекрытых линий стрельбы. Точные имена есть в доказательстве. Это **проверка БД**, не доказательство всех эффектов в бою.

Автор заявляет изменение препятствий для стрельбы и поведения стрелков в ближнем бою, а также большую значимость дружественного огня. Нам ещё нужны отдельные измерения этих эффектов. Название «линия видимости» не разрешает раскрывать скрытых врагов: фильтр видимости стороны, сохранённая последняя известная позиция и отмена приказа по скрывшейся цели обязательны. Зависимость не расширяет API наблюдений и команд.

## Как запускаем

- Используем competition runner; задание явно содержит `mod_profile: true-sight-v1`.
- Подготовка зависимости проверяет скачанный Workshop pack и фиксирует его байты рядом со сборкой. Отсутствие или другой хеш останавливают подготовку. Автоматического перехода на ваниль или принятия обновления нет.
- В заголовке PFH5 нашего pack указана зависимость `true_sight.pack`. В отдельном списке запуска явно указаны сначала True Sight, затем наш pack. Настройки модов пользовательской кампании не меняются.
- Запуск проверяет текущую и зафиксированную конфигурацию, хеши и существующую копию в data игры. Чужой отличающийся файл не перезаписывается. Совпадающий существующий файл сохраняется; созданная нами копия удаляется после закрытия нашего процесса. Скачанный Workshop файл остаётся.
- `manifest.json`, `mod-load.json`, сохранённый `mods.txt` и `result.json` каждой стороны содержат зависимость. Это подтверждает переданные файлы и список загрузки; чтения каждого действующего значения БД из движка здесь нет.
- Старые самостоятельные ванильные команды установки/запуска отключены явной ошибкой. Отдельный сборщик также фиксирует обязательный мод; общая функция упаковки по умолчанию добавляет его в заголовок зависимости. Старые доказательства и зафиксированные исходники сохраняются. Новая диагностика должна использовать или внедрить те же проверки зависимости.

## Сравнение и обновления

Бои **0003–0004 — ванильные**, **0005–0007 — с True Sight**. Останавливаемся после прежних пяти боёв; не начинаем цикл заново и не добавляем бои. Изменение результата на этой границе нельзя объяснять только улучшением алгоритма. Будущие чекпоинты также требуют этот профиль, но текущая задача не разрешает их запуск.

После обновления Workshop координатор проверяет изменения, фиксирует новый профиль/хеш, проводит нужные проверки совместимости и уведомляет все роли до следующего допуска. Зависимости чекпоинта неизменны. Старые доказательства механик остаются ванильными; затронутые выводы о стрельбе и ближнем бое надо перепроверить, прежде чем называть проверенными с True Sight.

Проверки координатора перед продолжением: 26 общих Python/Lua тестов пройдены, включая отказ при отсутствующем/изменённом моде, целостность фиксированных файлов, заголовок зависимости PFH5 и прежние проверки скрытой информации. PowerShell проходит синтаксическую проверку. Эффект каждого параметра в бою пока не измерен. Проверка интеграции: бой0005 затем завершился с этим профилем на настройке ×20; подтверждены файлы/список загрузки, закрытие игры и удаление нашей копии зависимости. Это не чтение действующих значений БД и не контролируемое сравнение эффективности мода.
