# Команды, проверенные в бою

[Отряды](README.md) · [English](../../../en/game/units/commands.md) · [Доказательства](evidence.md)

Создаём отдельный контроллер на отряд:

```lua
local uc = army:create_unit_controller()
uc:add_units(unit)
uc:take_control()
```

Теперь отрядом управляет скрипт. Координаты точки — игровые X/Y/Z; высоту земли Y читаем через `bm:get_terrain_height(x,z)`.

| Задача | Проверенный вызов | Что произошло |
|---|---|---|
| Идти / бежать в точку | `uc:goto_location(p, false)` / `true` | Все три отряда двигались соответствующим темпом и останавливались по прибытии |
| Занять позицию с нужным фронтом и шириной | `uc:goto_location_angle_width(p, 90, width, false)` | Пехота выполняла приказы ширины 15 и 50 м; перестроение видно и по координатам отдельных бойцов |
| Повернуться | `uc:rotate(90, false)` | Относительный поворот на +90°, в том числе с 270° на 0° |
| Остановиться | `uc:halt()` | Отряды тормозили и останавливались; мгновенной остановки нет |
| Атаковать врукопашную | `uc:melee(true); uc:attack_unit(enemy, false, true)` | Все три вступали в схватку, получали урон; лучники не тратили стрелы |
| Выйти из схватки | `uc:goto_location(p, true)` в удалённую точку | Все три отряда выходили из контакта; в процессе могли получать урон |
| Стрелять по указанной цели | `uc:melee(false); uc:fire_at_will(false); uc:attack_unit(enemy, true, false)` | Лучники стреляли по приказу, хотя свободный огонь выключен |
| Разрешить самостоятельную стрельбу | `uc:fire_at_will(true)` | Лучники сами выбирали доступную цель и тратили стрелы |
| Прекратить стрельбу | `uc:halt(); uc:fire_at_will(false)` | Новая длительная стрельба прекращалась; уже начатые выстрелы могли завершиться |
| Включить / выключить оборону | `uc:change_behaviour_active('defend', enabled)` | Доступно всем трём; включённый режим прекращал преследование бегущего врага |
| Отдохнуть | `uc:halt()` и подождать | Усталость уменьшалась естественно |
| Покинуть поле | `uc:withdraw(true)` | Работает в сценарии с явным разрешением отхода; успех проверяем по состоянию отряда |

Для генерала параметр ширины принимается, но **один человек не строится в несколько шеренг**. Координаты отряда и точки приказа не обязаны совпадать: пехота завершала движение в нескольких метрах от заданного ориентира. Проверка прибытия через точное равенство координат неверна.

## Как останавливать лучников

`fire_at_will(false)` запрещает самостоятельный выбор цели, но **не отменяет явный приказ стрелять**. В двух завершённых базовых опытах после этого переключения ушло ещё **153 / 138 стрел**.

Комбинация с `halt()` прекращала длительную стрельбу. В разных этапах остановки завершалось ещё **0–4 выстрела**. Уже выпущенные стрелы не исчезают.

`ammo_left()` у 90 целых лучников вернул **1800**: по 20 стрел на бойца. Это общий счётчик в данном сценарии. Дальность `missile_range()` — **130 м**. Само попадание цели в этот радиус не гарантирует возможность выстрела: препятствия и условия видимости здесь отдельно не исследованы.

В проверенном рецепте одновременно задаются `melee(...)` и аргумент `primary` у `attack_unit`. Взаимозаменяемость всех сочетаний этих параметров не проверена.

## Оборона не равна подготовленному строю

После принудительного бегства противника отряды с обороной сместились на **0,01–1,66 м**. Без обороны — на **78,05–91,39 м**, сохранив цель атаки. Бегство врага задавалось скриптом только для сравнения поведения.

`defend` не является командой окопаться или получить броню. Состояние `braced` возникало и при выключенной обороне. Подробности — в [состояниях](states.md).

## Особенности текущего Lua

В рабочем сценарии отхода у обеих армий задано `<can_withdraw>true</can_withdraw>`. Генерал объявлен через `<general><name>Unit action diagnostic</name><star_rating level="1"/></general>`. В ранних сценариях без этих объявлений `withdraw(true/false)` принимался, но отряды не уходили. Объявления добавлены вместе: опыт не выделяет отдельный вклад каждого из них.

`withdraw()` без параметра выдаёт ошибку в этой сборке. В установленной библиотеке `lib_battle_script_unit.lua` параметр называется `should_run`. Старую справочную сигнатуру без аргументов использовать нельзя.

Проверенный вызов способности генерала на себя:

```lua
if unit:can_perform_special_ability(key) then
    uc:perform_special_ability(key, unit)
end
```

Stand Your Ground и Foe Seeker создавали соответствующие действующие эффекты. Без явно переданной цели возникала ошибка. Доступность читаем у конкретного отряда; это не подтверждение прокачки лорда первого уровня в кампании.

Автоматическую перестрелку в опытах отключали. Для своего алгоритма это необязательная встроенная автоматика. Недоступное изменение плотности строя не вызывали. Команд «поднять щит», «окопаться» или мгновенно восстановиться в подтверждённом наборе нет.
