# Ростер отрядов

[← Назад](README.md) · [Отряды](README.md) · [English](../../../en/game/units/roster.md) · [Карточки отрядов](catalog/README.md)

Ростер — заранее собранные данные о каждом типе отряда: карточка, как её видит
игрок, и измеренный строй при каждой ширине.

Один файл на тип: `data/roster/<ключ отряда>.json`. Эти данные не нужно
разбирать в бою. Отряды добавляем постепенно, по мере того как их проверяем.

Состав армии и карточки вражеских отрядов игрок видит до боя, поэтому ростер
по **типам** врага — честные данные. Позиции и состояние врага в бою —
по-прежнему только видимые.

## Что в файле

| Часть | Откуда | Что внутри |
|---|---|---|
| `card` | Бой, автоматически | Карточка, как её видит игрок: `StatList` (броня, атака, защита, урон, натиск, скорость, мораль, стрелы, дальность…), масса, здоровье, класс, вид отряда, скорости, способности. Дата, версия игры, прогон |
| `formation` | Наш замер | Для каждой приказанной ширины: фронт × глубина, время перестроения из 30 м |
| `ours` | Вписываем руками | `fire`: `arc` (навесом), `direct` (прямой наводкой) или `null`; `roles` (пока пусто); заметки |
| `battle` | Позже | Проверенное в боях: сколько держится, сколько убивает |

`update` переписывает только `card` и `formation`; `ours` и `battle` не трогает.

## Как добавить отряд

1. Дописать ключ и число бойцов в `config/roster/capture.json` (до 5 отрядов за
   прогон — по числу мест на карте; одна фракция на прогон).
2. Собрать и запустить:

```bash
.venv/Scripts/python -m tools.build roster-capture
```

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/launcher/launch.ps1 -Target roster-capture
```

3. Обновить ростер из лога прогона и посмотреть:

```bash
.venv/Scripts/python -m tools.roster update build/roster-capture/runs/<время>/events.jsonl
```

```bash
.venv/Scripts/python -m tools.roster show
```

4. Заполнить `ours` руками (тип огня, заметки).

Прогон на 3 отряда занимает около 10 с реального времени на x20 и завершается сам.

## Что карточка не даёт и странности

- **Мораль на карточке = 0** у всех трёх в расстановке (в базе игры у лучников 50).
  Причина не выяснена; мораль из карточки пока не используем.
- **Нет разбивки урона** на обычный и бронебойный, ни у оружия, ни у стрел:
  на карточке только сумма. Для расчёта «пробивает ли» разбивку надо взять
  из базы игры или другого поля — не найдено.
- **Щиты:** у копейщиков и лучников щитов нет; у генерала щит есть, но строки
  для него на карточке нет. Как карточка показывает защиту щита от стрел, не
  проверено.
- `starting_ammo` (native) = стрел на весь отряд (1800 = 20 × 90), а `stat_ammo`
  на карточке — на бойца.
- `Name` генерала — имя из сценария («Roster»), а не название типа.
