# Каталог боевых отрядов

[← Назад](../README.md) · [Отряды](../README.md) · [Знания об игре](../../README.md) · [English](../../../../en/game/units/catalog/README.md)

Короткие карточки, сгруппированные по фракциям. Это указатель проверенных описаний и исходных записей, а не весь ростер игры и не отдельная база баланса. Наличие карточки само по себе не разрешает отряд в любом составе боя.

| Фракция | Пока добавлены |
|---|---|
| [Империя](empire.md) | Пеший генерал Империи, копейщики без щитов, лучники |

У каждой фракции своя папка. В карточке — русское/английское название, точный игровой ключ и вариант, тип и вооружение, несколько подтверждённых особенностей, условия проверки и ссылки на подробности. Другие фракции и отряды добавляем по мере необходимости; непроверенные способности и числа по памяти не заполняем. Основной язык — английский.
