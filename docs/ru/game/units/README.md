## Условия опытов

Испытаны **120 копейщиков без щитов**, **90 лучников**, **пеший генерал Империи**. Опыт отрядов нулевой, размер Ultra, заданная скорость ×20, минимальная графика. Загружен только диагностический скрипт; таблицы характеристик не менялись. В итоговом сценарии генерал действительно командующий первого уровня: игра отдельно подтвердила роль, уровень персонажа 1 и опыт отряда 0.

**Способности XML-боя не равны прокачке в кампании.** Генерал первого уровня в нашем XML-сценарии получил две активные способности и Hold the Line. Это не доказывает, что они есть у только что нанятого лорда кампании. Способности нужно каждый раз читать у конкретного отряда.

Здесь собраны наблюдения и их ограничения. Непроверенные гипотезы остаются в игнорируемой папке `tmp/unit-actions/`. Игры после опытов закрываются.
