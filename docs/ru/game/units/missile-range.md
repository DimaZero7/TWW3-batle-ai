# Дальность стрельбы

[Отряды](README.md) · [English](../../../en/game/units/missile-range.md) · [Видимость](../../apps/intel.md)

**Проверено 26.09.2026:** Lua отдаёт дальность стрельбы собственных отрядов, отдельной союзной армии и видимых врагов. Проверены стрелковая и гибридная пехота. Дальность обзора сюда не входит. **Видимость врага проверяется до чтения дальности и попарных запросов.** Это обязательное [правило доступа](../../apps/intel.md).

## Какие данные получаем

| Запрос | Формат | Что установлено |
|---|---|---|
| `unit:missile_range()` | число, метры | Текущее значение движка; после принудительного обнуления боезапаса стало нулём |
| Карточка `scalar_missile_range` | числа `Value`, `DisplayedValue`, `ValueBase` | Показатель карточки; при пустом боезапасе сохранил дальность оружия |
| `source:unit_in_range(target)` | да/нет | Проверка радиуса для пары; **не** гарантия стрельбы или наличия стрелкового оружия |
| `source:unit_distance(target)` | число, метры | Расстояние с учётом габаритов отрядов, отличается от расстояния между центрами |
| `centre_distance_xz_m` | число, метры | Наш расчёт между позициями отрядов на плоскости XZ; это не проверка радиуса движком |

Для карточки перебираем `CcoBattleUnit.UnitDetailsContext.StatList`, находим `Key == 'scalar_missile_range'` и читаем значения строки. Индекс не фиксируем, переведённое название не разбираем. Отсутствующая строка означает неизвестное значение, не ноль. Все три значения карточки здесь совпали; усиления дальности, улучшения, сменные виды оружия и произвольные отряды не проверены.

| Тестовый отряд | Со стрелами/патронами: движок / карточка | Принудительно пустой боезапас: движок / карточка |
|---|---:|---:|
| Лучники Империи, `wh2_dlc13_emp_inf_archers_0` | 130 / 130 | 0 / 130 |
| Ополчение, `wh_dlc04_emp_inf_free_company_militia_0` | 90 / 90 | 0 / 90 |
| Копейщики без щитов, `wh_main_emp_inf_spearmen_0` | 0 / строки нет | Не применимо |

Это результаты конкретных опытов, а не константы для алгоритма. В установленной базе ополчение использует пистолет и имеет назначение ИИ `hybrid_melee`. У отдельной союзной армии №2 и видимых врагов базовые числа совпали. Сетевое владение союзником и точное соответствие экрану игрока этим не проверены.

После успешных команд `controller:melee(true)` и `melee(false)` дальность оставалась 130/90. Подтверждён опыт с приказом переключения; независимого чтения текущего режима не было. `is_in_melee()` относится ко всему отряду и не доказывает контакт с выбранной целью. `set_current_ammo_unary(0)` обнулил боезапас и нативную дальность, но сохранил число карточки; восстановление боезапаса восстановило дальность. **Естественное исчерпание боезапаса не проверялось.**

Остановленный отряд с боезапасом и целью в радиусе мог иметь `IsFiringMissiles=false`. После приказа атаковать появлялась стрельба и расходовался боезапас. Проверка радиуса не заменяет видимость, боезапас, факт стрельбы и проверку препятствий. У копейщиков было 47 разрешённых наблюдений с нулевой дальностью, нулевым расстоянием между габаритами и `unit_in_range=true`: одного этого ответа недостаточно, чтобы признать отряд стрелковым.

## Граница радиуса

Примеры последнего запуска после 20 игровых секунд ожидания; стрелки сообщали, что не движутся и не стреляют:

| Отряд | Дальность | Между центрами XZ | Расстояние движка | Цель в радиусе |
|---|---:|---:|---:|---|
| Лучники | 130 | 138,956 | 126,527 | Да |
| Ополчение | 90 | 98,459 | 87,089 | Да |
| Лучники, цель дальше | 130 | 148,935 | 136,621 | Нет |
| Ополчение, цель дальше | 90 | 109,990 | 97,101 | Нет |

В 7636 разрешённых попарных наблюдениях ответ совпал с `unit_distance <= missile_range`; сравнение по центрам расходилось 354 раза. Это результат данных опытов, **не универсальная формула вместо запроса движка**. Испробованы заданные ширины 10/30/60 м и повороты 0/90/180/270°, но после телепортации позиции и строй смещались. Берём измеренные значения, а не названия этапов или назначенные координаты. Точный контур сектора огня, минимальная дальность, влияние препятствий/высоты и геометрия экранного круга не получены.

`Точные примеры и номера строк JSONL` (локальный архив: `research/evidence/units/missile-range-20260926/measured-examples.json`). Открытые номера относятся к распакованным разрешённым журналам; соответствующие всеведущие исходные строки остались у инициатора.

## Модуль и защита от раскрытия врагов

[src/units/range.lua](../../../../src/apps/units/) — отдельный модуль чтения, **пока не подключённый к API v1 бойцов**. Внутренний вызов: `observe(source, target_or_nil, context)`. Только доверенный адаптер имеет игровые объекты и задаёт наблюдающий альянс, проверку союзной принадлежности `is_friendly` по реальному списку альянсов/армий, CCO-провайдер и время. Политика не может объявить врага союзником.

До чтения дальности, карточки, расстояния и позиций проверяются оба участника пары. Свои/союзные допускаются по проверенной принадлежности; враг — только если нативная видимость для альянса равна `true`. Скрытый враг, ошибка и неизвестная видимость блокируют все чувствительные вызовы. Текст ошибки движка не раскрывается. Дальность одного разрешённого отряда можно запросить внутри адаптера без цели. Если передана скрытая цель, блокируется вся пара, включая дальность стрелка.

Результат содержит простые `sensors`: `missile_range_m`, значения карточки, а для пары ещё `unit_in_range`, `unit_distance_m`, `centre_distance_xz_m`. Каждое поле — `{status='known', value=...}` или `{status='unknown', reason=...}`; известные ноль и ложь сохраняются. Политика не получает игровые объекты и свободную функцию запросов к любым парам. Памяти в модуле нет: `observed_ms` — время попытки наблюдения, а не обновлённое время старого значения. Будущий слой памяти обязан сохранять прежние значения и время при скрытии.

Во всех 759 заблокированных игровых наблюдениях выполнено **ноль** чувствительных вызовов. Тесты покрывают скрытого стрелка/цель, двух врагов, чтение без цели, ошибки/nil/неверный тип видимости, отсутствие принадлежности/наблюдателя и переход виден→скрыт→виден. Это проверенный фильтр, не изоляция ОС и не гарантия непрерывной видимости движка.

## Доказательства и воспроизведение

Три успешных запуска, 11235 наблюдений: `range` — 3900, `fog` — 2040, `boundary` — 5295. WH3 v9.0.0 build 50218.4334952, неизменённая игровая база, только нейтральный диагностический скрипт, минимальная графика, Ultra, ×20. Карты: `chokepoint_badlands_river`, затем `wh3_main_macro_ksl_plains_01/catchment_04`. В первом альянсе две отдельные армии, во втором одна. Телепортации, тестовые приказы и изменение боезапаса разрешены только диагностике. Все три игры закрыты, временные установленные файлы удалены.

`Сводка` (локальный архив: `research/evidence/units/missile-range-20260926/summary.json`) · `Хеши архива` (локальный архив: `research/evidence/units/missile-range-20260926/archive.json`) · `Выдержка базы` (локальный архив: `research/evidence/units/missile-range-20260926/database.json`) · `Источники исследования` (локальный архив: `research/evidence/units/missile-range-20260926/research.json`).

Открытый архив содержит точные скрипты/XML/модуль, разрешённые журналы, сведения о запуске/закрытии и диагностические поля своих отрядов. Всеведущие исходные журналы и их полный анализ не опубликованы. Автор опытов — инициатор; проверка публикации — координатор. Пройдены шесть тестов дальности и шесть прежних тестов состояния. Проверка хешей и точная пересборка без запуска:

```text
python -X utf8 tools/unit-range/replay.py range
python -X utf8 tools/unit-range/replay.py fog
python -X utf8 tools/unit-range/replay.py boundary
python -X utf8 -m unittest discover -s tests -p test_unit_range.py
```

Необязательный `--output <новый-путь-пакета>` сохраняет пакет без перезаписи. Установки и запуска нет. Для будущего опыта нужны владение запуском у инициатора и новый каталог доказательств.
