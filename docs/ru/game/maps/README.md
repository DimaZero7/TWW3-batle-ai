# Каталог боевых карт

[← Назад](../README.md) · [Документация](../../README.md) · [Знания об игре](../README.md) · [English](../../../en/game/maps/README.md)

Карточки конкретных официальных карт, сгруппированные по регионам и культурам. [Инструкция по сбору карты](../map/README.md) описывает методы; здесь храним идентификаторы, проверенные свойства и ссылки на готовые измерения.

| Регион | Карта | Подтверждение |
|---|---|---|
| Луга Империи | [The Moorlands Route](moorlands-route.md) | База игры, официальное превью и игровой замер местности с шагом 3 м |

Карту определяют ключ базы, ресурс местности, участок `catchment`, вариант `tile_upgrade` и условия сценария. Один ресурс местности может содержать разные поля боя. Нельзя переносить сетку другого участка или считать нулевые размеры в базе реальными размерами карты.

В каждой карточке разделяем данные базы, игровые измерения и неизвестное. Подтверждённый замер сохраняет хеши сценария и исходников, версию игры при доступности, координаты, шаг сетки, время измерения и ограничения. Для высоты, леса, воды и объектов даём ссылки на данные и метод. Здесь публикуем только местность: позиции армий, закрытые боевые логи и алгоритмы сюда не входят.

Оба бойца получают одну карточку. Она экономит повторный поиск, но алгоритмы по-прежнему читают разрешённые данные во время боя и должны работать на других картах. Карточка не разрешает зашивать маршруты, позиции появления противника или скрытые сведения.
