Карту определяют ключ базы, ресурс местности, участок `catchment`, вариант `tile_upgrade` и условия сценария. Один ресурс местности может содержать разные поля боя. Нельзя переносить сетку другого участка или считать нулевые размеры в базе реальными размерами карты.

В каждой карточке разделяем данные базы, игровые измерения и неизвестное. Подтверждённый замер сохраняет хеши сценария и исходников, версию игры при доступности, координаты, шаг сетки, время измерения и ограничения. Для высоты, леса, воды и объектов даём ссылки на данные и метод. Здесь только местность: позиции армий и журналы боёв сюда не входят.

Карточка экономит повторный поиск, но ИИ — и будущая нейросеть — должен читать местность в бою и работать на других картах. Карточка не разрешает зашивать маршруты, места врага или скрытые сведения.
