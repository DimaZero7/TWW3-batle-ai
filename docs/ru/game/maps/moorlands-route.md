# The Moorlands Route — луга Империи

[← Назад](README.md) · [Каталог карт](README.md) · [English](../../../en/game/maps/moorlands-route.md)

Выбрана как стартовая полевая карта для `iteration-0001`. Это первый тест нашего проекта; принадлежность к самому первому бою кампании Карла Франца или другого лорда не проверена. База установленной игры подтверждает обычный наземный бой Creative Assembly. Название взято из имени официального превью; локализованную подпись пока не извлекали.

![Официальное превью в меню](../../../../research/evidence/maps/moorlands-route/preview.png)

На превью видны травянистые холмы, отдельные группы деревьев и дорога. Это иллюстрация из меню: по ней нельзя точно определить высоты, проходимость или видимость.

## Геометрия и повторное использование

Игровой замер выполнен 26 сентября 2026 года. Запрошен `catchment_03`; XML игры подтвердил ресурс местности и рассчитанное положение `(0.453125, 0.40625)`. В экспортируемом XML нет названия catchment: связь подтверждается входным XML, манифестом и журналом запуска, а не независимой расшифровкой ресурса участка. Сборка: `v9.0.0 Build 50218.4334952 (modded)`; пометку modded вызывает диагностический пакет.

Порядок матриц: `[iz, ix]`; Z растёт по строкам, X — по столбцам. Центры клеток: `x=-512+(ix+0.5)*3`, `z=-512+(iz+0.5)*3`. Центры последней строки и столбца выходят за рамку; узкие оставшиеся внутри части этих клеток не измерены. Сохранены CSV и NPY. Пакет содержит только местность, без алгоритмов бойцов, боевых позиций и сведений о противнике.

Перед успешным замером был сбой запуска. Удаление BOM из XML предшествовало успеху, но причина сбоя окончательно не установлена. Игра закрыта, установленные файлы пробы удалены. Склоны можно рассчитать из высот, но для этого замера они ещё не опубликованы. Проходимость для выбранных отрядов Империи и действующие бонусы сооружений не проверены.

Уже проверены методы получения [рамки](../map/boundaries.md), [сетки](../map/sampling.md), [высот](../map/heights.md), [растительности](../map/vegetation.md) и [объектов](../map/objects.md). Рамка радара не равна доказанной стене движения; замер в центре клетки не описывает всю клетку. Достижимость для конкретного отряда требует отдельной проверки.

Обе стороны итерации получают одинаковую карточку и API v1. Состав армий указан в задании. Расстановку, погоду и условия боя фиксирует инициатор; их нельзя угадывать по превью. Алгоритмы не должны содержать привязку к этой карте или знание скрытых позиций противника.
