## Что получаем

| Результат | Значение |
|---|---|
| Рамка мини-карты в мировых координатах | Измеренная система отсчёта; точная граница движения пока не доказана |
| Высота земли в X/Z | Одно число, а не полная трёхмерная сцена |
| Тип поверхности в точке | Строка: например, `grass`, `forest`, `rock` |
| Лесная сетка 3 м | Ответ `forest` в центрах клеток; влияние на отряды не измерялось |
| Выбранные точки деревьев в проверенном сценарии Кислева | Прочитаны из ресурсов и сопоставлены с рельефом; это не живой список Lua и не карта столкновений |
| Ответ об ограничениях области | `is_area_clear` для прямоугольника, а не готовая проверка маршрута |
| Наша сетка клеток | Производное представление с заданным шагом в метрах, началом и размерами |
| Мелководье и глубокая вода | Типы земли в центрах клеток, без измерения глубины |
| Расчётные уклоны и перепады | Геометрия из сохранённых высот, без формулы игровых штрафов |
| Список физических объектов | Положение, название и состояние; полнота геометрии не доказана |
| Доступность точки отряду | Проверена после расстановки; это не маршрут и не проверка прямого отрезка |
| Три переправы Катая | Найдены по сетке и пройдены кавалерией и пехотой |
| Мост и поля CCO | Один мост распознан; проход и геометрия настила не подтверждены |

## Порядок работы

Прочитать преобразование мини-карты в загруженном бою → проверить четыре угла →
выбрать шаг сетки → опросить клетки на местной высоте → сохранить данные и
условия → проверить полноту → построить и объяснить изображение.

**Не называть рамку мини-карты доказанной границей движения. Не трактовать
отрицательный ответ как непроходимость каждого метра клетки.**

Рабочий ландшафт — штатные Равнины Кислева, `wh3_main_macro_ksl_plains_01`,
фиксированный полевой сценарий. Текущая рекомендация — клетки 2 м; доступен
разовый более подробный замер 1 м. Это не утверждение схемы входов нейросети.

Новые черновики — в `tmp/`. Для подтверждённого результата сохранять исходные
данные, хеши, условия и ограничения. Основной язык — английский; обе версии
инструкции должны содержать одинаковые факты.
Не добавлять исследовательские списки и непроверенные кандидаты API в эту
инструкцию или её оглавление.

Сохранены и отрицательные результаты полевых проверок: карта `scrub`,
проход по найденному мосту, универсальная ширина узких проходов и активные
ауры сооружений пока не подтверждены. Осады и поселения остаются за рамками работы.

[Карточки конкретных карт](../maps/README.md) хранят готовые данные; здесь остаются методы их получения.
