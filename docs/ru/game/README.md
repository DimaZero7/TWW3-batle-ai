## Какие данные доступны через Lua

- **Карта**: высота точки, мировые координаты и сетка, тип грунта, вода и
  лес, статические объекты, проверка достижимости точки конкретным отрядом.
- **Свои отряды**: тип, позиция, численность, здоровье, движение, бой,
  бегство, боезапас, дальность, приказы и часть параметров строя, поля
  карточки CCO.
- **Противник**: только текущее видимое состояние и последняя известная позиция.
- **Команды**: движение, бег, атака видимой цели, остановка, оборона, строй и
  ширина, часть способностей.

Недоступно или неполно: точный внутренний запас морали, свежие физические
контуры всех бойцов, скрытое состояние невидимого врага, гарантия выполнения
приказа по факту его принятия, универсальная карта проходимости без проверки
конкретным отрядом.

Страницы перенесены из исследовательского набора и местами называют модули
по-старому. Соответствие:

| В тексте | Сейчас |
|---|---|

| `src/map/objects.lua` | [map](../apps/map.md): `read_buildings`, `read_structure_contexts` |
| `src/map/reachability.lua` | [navigation](../apps/navigation.md): `read_cells` |
| `src/units/state.lua`, `src/units/range.lua` | [units](../apps/units.md): `state_adapter`, `range_adapter` |
| `src/visibility/reader.lua` | [intel](../apps/intel.md) |
