**Фаза 3 по порядку** (абстрактно; каждую потом разбираем отдельно, с карточкой). Думаем, как было бы в реальном
бою; штатный ИИ — мишень, не образец.

| № | Задача | Вопрос |
|---|---|---|
| 3.1 | Видеть, что враг пошёл | Кто идёт, куда, всей линией или по одному, когда дойдёт |
| 3.2 | Огонь, пока враг идёт: **фокус цели** | По кому стрелять: ближний, вырвавшийся вперёд, опасный для фланга |
| 3.3 | **Встречный удар, вариант Б**: бьёт отряд под ударом, соседи — во фланг | Когда начинать, кто идёт, как не порвать линию. Сначала замер: бонус удара, встречный бой против приёма на месте |
| 3.4 | Сошлись: лучники переносят огонь | Куда бить, чтобы не попадать по своим |
| 3.5 | **Прорывы: предсказание и контроль** | Где враг прорвётся; лучники фокусируются на этих местах |
| 3.6 | Переход дальше | Признаки фазы 4 (их лучники бьют стену) и фазы 5 |
