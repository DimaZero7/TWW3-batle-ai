# observation

[Документация](../README.md) · [Приложения](../architecture/apps.md) · [English](../../en/apps/observation.md)

**Сводка одной стороны** — единственное, что сторона ИИ имеет право получить.
Код: `src/apps/observation/`.

## Два режима сводки

| Режим | Кто строит | Что внутри | Для чего |
|---|---|---|---|
| Сводка стороны | `observation.adapter.observe_side` | Свои отряды целиком (68 полей); о врагах — видимость, позиция **только пока виден**, последняя известная позиция; дальность своих стрелков (скрыта для невидимых целей) | Вход ИИ, проверка «не палим скрытых» |
| Полная сводка | `telemetry.sampler_adapter.sample` | Все отряды обеих сторон, включая скрытых: позиции, здоровье, мораль, видимость для каждой стороны | Эталон для проверки, анализ после боя. **Никогда не вход ИИ** |

## adapter

`observe_side(ctx)`: `ctx = {side, alliance, own, enemies, memory, cco, now_ms, shooters}`
→ `{side, time_ms, own = {имя → показания}, enemies = {имя → запись intel}, range = {"стрелок>цель" → показания}}`.

## services

- `check(view)` — самопроверка при каждом построении; ошибка, если в записи
  о враге есть поле кроме `id, visibility, sampled_ms, current, last_seen,
  position_status`, если у невидимого врага есть текущая позиция или если
  дальность до невидимого врага не скрыта.
- `visibility_counts(view)` — сколько врагов видно / скрыто.

## Проверка на утечки

`python -m tools.analysis.unit_readout <прогон> --view side --side 1` сравнивает
сводку стороны с полной сводкой как эталоном: поля записей о врагах, текущая
позиция скрытых, дальность до скрытых, «последняя позиция» — реальное прошлое
наблюдение, совпадение видимости. Результат 27.09.2026 (прогон `20260927-142521`):
**14 / 14 для каждой стороны**, утечек нет. Замеры механики — [видимость](../game/units/visibility.md).
