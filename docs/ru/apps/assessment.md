# assessment

[Документация](../README.md) · [Приложения](../architecture/apps.md) · [English](../../en/apps/assessment.md)

Оценка сил в начале боя. Чистый код: по составу обеих армий (данные
[ростера](../game/units/roster.md)) считает один набор признаков. Стратегии
только читают признаки и сами ничего не считают. Код: `src/apps/assessment/`.

| Функция | Что делает |
|---|---|
| `category(u)` | `lord` (один боец и командир), `shooter` (есть дальность), `infantry` (пехота без стрельбы), `other` (конница и прочее) |
| `melee_power(u)` | Сила пехоты: здоровье × (атака + защита) / 100 |
| `ranged_power(u)` | Сила стрелков: бойцы × урон выстрела |
| `strength(u)` | Одно число «насколько отряд силён»: сила в ближнем бою плюс сила стрельбы у стрелков; по нему [видение](vision.md) ищет основную армию |
| `side(units)` | Число отрядов по видам, сила пехоты и стрелков, доля навесного огня, средняя броня пехоты |
| `assess({role, own, enemy})` | Обе стороны и отношения сил: `melee_ratio`, `ranged_ratio` |

Формулы силы — первый черновик; уточняются по боям. Неизвестное значение карточки
не считается нулём: вместо здоровья берутся бойцы, вместо урона — 1.
