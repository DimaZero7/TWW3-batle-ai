# mem

[← Назад](README.md) · [Документация](../README.md) · [Приложения](../architecture/apps.md)

Чтение памяти игры через мод memreader Plus — **только в пробах** (сборка `--mem`), не в бою сети и не в экзаменах.
Код: `src/apps/mem/`. Что подключено, границы, как запускать и что проверено — [чтение памяти игры](../game/memreader.md).

## projectiles — снаряды в полёте

| Функция | Что делает |
|---|---|
| `check(mr, cfg)` | `{ok, why, version, plus_version, sites}`: мод загружен, у каждого места совпали байты (сборка игры) и сигнатура нашлась ровно один раз на том же адресе |
| `attach(mr, cfg)` | проверки, затем перехваты: `proj_update` (простой, только счётчик — функция идёт в потоке симуляции) и `ammo_left` (префикс патчера: читает отряд боя и его боезапас); `handle, status` или `nil, status` (проба идёт без памяти) |
| `handle.poll()` | один опрос списка снарядов (таймер пробы, 100 мс боя); путь к менеджеру ищет сам |
| `handle.drain()` | что накопилось с прошлого раза: `calls`, `spawn`, `state`, `gone`, `fly` (летящие сейчас), `records`, `ammo` (чтения перехвата), `chain` (путь к менеджеру), `discover`, `errors` |
| `handle.stats()` / `handle.detach()` | счётчики memreader / снять оба перехвата |
| `manager(mr, cfg, unit, off)` | менеджер снарядов: бой → мир → менеджер, мир должен ссылаться обратно на бой; бой — из `battle_global` или из отряда боя (`u_battle`) |
| `discover(mr, L, from, max)` | поля `from` (шаг 8), где лежит бой или мир (проверка ссылкой обратно); так найдено поле `u_battle` |
| `scanner(mr, L, max)` | разбор списка за один опрос (без игры — для тестов на поддельной памяти); ушёл — после `MISS_POLLS` (3) опросов без него |
| `address(mr, site)` | адрес места: `base + hi × 2²⁰ + lo` (числа Lua в игре 32-битные) |

## entities — бойцы отряда

| Функция | Что делает |
|---|---|
| `attach(mr, cfg)` | проверки (`projectiles.check`), префикс на `ammo_left`; `handle, status` или `nil, status`; в `status.dir_table` — векторы взгляда из таблицы игры |
| `handle.bind(name, unit)` | привязать скриптовый отряд: зовёт `unit:ammo_left()`, префикс видит боевой отряд; проверка: каждый боец вектора — этого отряда |
| `handle.unhook()` | снять перехват (после привязки) |
| `handle.poll(names)` | один опрос бойцов названных отрядов: `{c, tick, tick_end, cost, units = {name = {n, rows}}, new}`; строка — поля `ROW` |
| `handle.discover(from, to, n)` | смещения (шаг 8) у n бойцов `from`, где лежит указатель на бойца `to`: `{смещение = раз}` (только поля самого бойца) |
| `reader(mr, L)` | то же без игры — для тестов на поддельной памяти |

`cfg` — `config.mem` пробы: места и смещения из `build/mem/sites.json` (вне git), в коде только имена. Тесты:
`tests/apps/mem/test_projectiles.py`, `tests/apps/mem/test_entities.py`.
