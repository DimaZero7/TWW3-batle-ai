# formation

[Документация](../README.md) · [Приложения](../architecture/apps.md) · [English](../../en/apps/formation.md)

Строй армии по ролям, которые назначила [стратегия](strategy.md); почему выбрана стратегия, строй не знает. Чистый код без движка: одинаково работает в бою и в
симуляции (`tools/sim/formation.py`). Код: `src/apps/formation/`.

## services

| Функция | Что делает |
|---|---|
| `plan(layout, input, params)` | Расставить отряды расстановкой `layout`. Сейчас одна: `line_and_blocks` — `wall` линией впереди, `arc` квадратами сзади, `lord` на фланге, `other` не ставятся |
| `facing(a, b)` | Направление из точки `a` на точку `b`, градусы (0 = +Z, 90 = +X) |
| `overlaps(placements)` | Пары отрядов, чьи прямоугольники пересекаются |
| `turn_in_place(middle, bearing, delta, depth)` | Точка и направление приказа, чтобы отряд развернулся вокруг своей середины. Движковый `rotate` вращает вокруг первой шеренги и сдвигает отряд ([команды](../game/units/commands.md#поворот-на-месте)) |

**Вход:** `anchor` — центр передней линии стены; `bearing` — куда смотрит строй;
`units` — отряды из [ростера](../game/units/roster.md) с ролью, дальностью и
**измеренными** размерами строя для каждой ширины.

**Как выбирает.** Перебирает измеренные ширины стены, ширины лучников и число
их рядов (до 3). У каждого варианта считает фронт и глубину стены, фронт
лучников, запас дальности (сколько метров самый дальний лучник достаёт за стену).
Жёсткие условия: лучники почти квадратом и не шире стены (с допуском `archer_overhang_m` с каждой стороны), стена не тоньше `min_wall_depth_m`,
запас дальности не меньше `min_reach_m`. Среди подходящих — лучший балл:
запас дальности + `wall_depth_weight` × глубина стены. Все варианты с баллами
возвращаются в `options` (журнал выбора).

**Выход:** `status` (`ok`, `infeasible` — ни один вариант не прошёл, выдан
лучший из плохих; `no_wall`), `choice`, `placements` — для каждого отряда точка
приказа (центр первой шеренги), направление, ширина, фронт, глубина, роль, ряд.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `wall_archer_gap_m` | 3 | От задней шеренги стены до первой шеренги лучников |
| `row_gap_m` / `unit_gap_m` | 2 / 1 | Между рядами лучников / соседями в линии |
| `lord_gap_m`, `lord_side` | 4, справа | Лорд на уровне стены, сбоку. Если вражеский лорд виден (`input.enemy_lord`), наш встаёт на ближний к нему фланг: его задача — связать вражеского лорда |
| `min_wall_depth_m` | 5 | Тоньше — не стена (около 3 шеренг) |
| `min_reach_m` | 80 | Каждый лучник бьёт хотя бы на столько за стену |
| `wall_depth_weight` | 100 | Чем толще стена, тем лучше (как фаланга): толщина решает, дальность только различает равные (правило пользователя) |
| `max_archer_rows` | 3 | |
| `archer_max_aspect` | 1,3 | Лучники стоят почти квадратом: фронт и глубина различаются не больше чем в 1,3 раза |
| `archer_overhang_m` | 10 | На сколько лучники могут выйти за край стены с каждой стороны |

**Место для разворота** (правило пользователя). Между отрядами лучников
оставляется промежуток, чтобы каждый мог развернуться на месте, не задев
соседа: сбоку — диагональ отряда минус фронт, между рядами — диагональ минус
глубина. Узкие глубокие колонны не подходят: развернувшись вправо или влево,
они перекроют друг друга.

Карту не учитывает. Параметры — первые предположения; их настраиваем по боям.
