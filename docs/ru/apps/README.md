# Модули кода

[← Назад](../README.md) · [Документация](../README.md) › Модули · [English](../../en/apps/README.md)

Каждый модуль `src/apps` — что делает, зачем, как устроен; и точки входа `src/entries`, которые собирают модули в зонды и записи боёв. Общий список — [список приложений](../architecture/apps.md).

- [telemetry](telemetry.md) — Запись того, что произошло в бою
- [units](units.md) — Состояние своих отрядов, дальность стрельбы, карточка отряда и позиции его бойцов
