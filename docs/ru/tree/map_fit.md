## Как работает

Маска «можно ли тут встать» (клетка 3 м) строится вокруг армии; каждый отряд
проверяется по своему прямоугольнику. Уступки — по порядку, ближайшая первой:

```mermaid
flowchart LR
  p["строй в заданной точке"] --> q{"все отряды<br/>помещаются?"}
  q -- да --> ok["как задумано"]
  q -- нет --> w{"другая ширина<br/>(6 лучших вариантов)"}
  w -- помещается --> ok2["другая ширина"]
  w -- нет --> s{"сдвиг: вбок до 90 м,<br/>назад до 60 м,<br/>шаг 6 м"}
  s -- нашлось --> ok3["сдвинут"]
  s -- нет --> t{"поворот на 1–2<br/>сектора (±5,6°, ±11,25°)"}
  t -- нашлось --> ok4["повёрнут"]
  t -- нет --> no["как задумано,<br/>с пометкой «места нет»"]
```
