# Документация

[← Назад](../../README.md) · [Проект](../../README.md) · **Русский** | [English](../en/README.md)

Здесь описана основа проекта: механика боя Total War: WARHAMMER III, которую мы
измерили, наши инструменты для работы с игрой и сеть для боя, обученная с нуля в нашем
симуляторе и проверяемая в игре. Прежний алгоритмический ИИ проекта удалён (решение
автора проекта); он в истории Git.

## Сводка проекта

- **[Сводка проекта](summary.md)** — вся система на одной странице: симулятор, обучение, учения,
  мост, проверки в игре; текущее состояние, главные цифры, что не совпадает с игрой. Читать первой.

## Инфраструктура

### Код в игре (`src`)

| Приложение | Назначение |
|---|---|
| [core](apps/core.md) | Проверки значений, JSON, коды ошибок, время |
| [battle](apps/battle.md) | Стороны, армии, отряды, роли атакующего/защитника, скорость, срок и застой боя |
| [map](apps/map.md) | Рамка радара, сетка, высоты, грунт, объекты |
| [navigation](apps/navigation.md) | Достижимость точек для конкретного отряда, конец захода |
| [units](apps/units.md) | Состояние своих отрядов, дальность стрельбы, карточка, позиции бойцов |
| [intel](apps/intel.md) | Видимость врагов и последняя известная позиция |
| [observation](apps/observation.md) | Сводка одной стороны — без скрытых данных |
| [orders](apps/orders.md) | Проверенные вызовы приказов, передача отрядов штатному ИИ, направления движка |
| [telemetry](apps/telemetry.md) | JSONL-события, файлы состояния, послебоевые снимки |
| [Точки входа](apps/entries.md) | Зонды и записи боёв: `nn_arena`, `ai_vs_ai`, `unit_readout`, `move_probe`, `archer_range`, `enemy_layout`, `roster_capture`, `manual_record`, `map_capture` |
