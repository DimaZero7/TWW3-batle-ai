# net/drill — движок учений v1

Один вход для любого уровня: `python -m net.drill.run train --card ID --out DIR [--init PARENT.pt]`. Уровень даёт
модуль `levels/<уровень>.py`, учение — карточку `cards/<id>.py`; интерфейсы — в docstring `levels/__init__.py` и
`cards/__init__.py`. `run`, `collect`, `fit`, `census`, `validate` не знают ни уровня, ни карточки.

- `record.py` — запись решения `Batch` (вход, приказ в силе, legal / dont_care, решено или передано, ход учителя,
  предложенный и исполненный); `masks.py` — одно определение «метка учит голову» для fit, переписи и V.
- `store.py` — осколки + манифест с ключом и раундом; чужой манифест и живой второй писатель — отказ, замок своего
  ключа без пульса 10 мин — перехват. Осколок хранит имя и хэш карты (`levels/tactic.remap`).
- `run.py` — расписание `rounds` (`aggregate` — отказ); публикуется раунд с остановкой; предел без сданных меток —
  `passed: false`, без `final.pt`, код 1; V0 — метки родителя до весов ребёнка, `card.reference` — то же для эталона
  (T0-1: останов относительно принятой сети). `card.stages` сборщик тактика пока не читает: новой карточке — код уровня.
- `census.py` — на каждый класс каждой головы минимум меток с градиентом (карточка, по умолчанию 50), доля
  безразличных, полоса; в дымовом прогоне минимумы не применяются (сказано в выводе).
- `seeds.py` + `registry.json` — реестр обязателен (повторы основ близнецов — реализованные); сбор проверяет каждый
  чанк на учебные диапазоны. `validate.py` — кэш пути учителя (повторное чтение переигрывает первый чанк) и остановка:
  каждая ячейка с n ≥ своего минимума (`card.mark_min`, по умолчанию 50), иначе раунд «не судим».
- `exam.py`, `verdict.py` — руки по ключу боя; M2: BLOCKED без NEG, при чужих весах NEG, неполных осях, малых
  стратах, неизвестном шлюзе, без пробы или с несданной; удвоение до 1 024; код 0 только PASSED. Умение — на +450 с,
  безопасность — на +450 с и на конце боя (своя строка), +300 с рядом. `levels/tactic_probe.py` — проба метки тактика
  (старты probe_* реестра, `masks.of`; со стёртой причиной не выше случая + 0,10 на парах близнецов).
- `reexam.py` — перепроверка принятых учений после правки симулятора (`python -m net.drill.reexam [--sim-set k=v]`):
  сцены учения на зёрнах `reexam`, B1 / тишина / цель / приказы против журнала, ~22 мин карты; `--lord-mode post|t2
  --buttons on|off` — лорды в бою (лорды сцен на посту 20 м, доля решений пехоты с аурой), `--ckpt` — кандидат.
Известное: ошибки повторных тактов одного боя в остановке сложены как независимые (экзамены — парные по боям); одна
годная по меткам эпоха от n_min — выбор расписания. V и held T0-2 начинают чанки torch с 2800: не разведены.
    python -m net.drill.verdict before --card t0_2 --dir EXAM_DIR        # шлюз ценности -> value_gate.json
    python -m net.drill.verdict after --card t0_2 --dir D --gate G --neg NEG --parent-sha SHA --probe P
Канарейка — `net/tests/test_smoke_train_torch.py::test_the_drill_engine_canary`.
