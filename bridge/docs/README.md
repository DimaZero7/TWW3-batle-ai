# Документация моста

Мост — мод на Lua внутри Total War: WARHAMMER III и помощник на Python вне игры (Docker). Раз в секунду боя мост
пишет в папку игры состояние всех отрядов, помощник (цепочка оперативник → тактики → сеть отряда) отвечает
приказами, мост отдаёт их нашим отрядам. Здесь — как это устроено и как запускать.

- [Модули кода](apps/README.md) — модули `bridge/lua/apps` и 6 точек входа `bridge/lua/entries`; сам мост к сети —
  [bridge](apps/bridge.md), память игры в пробах — [memreader](apps/memreader.md).
- [Сборка и запуск](launch/README.md) — сборка пака, запуск боя и результаты, бой цепочки.
- [Архитектура](architecture/README.md) — папки, слои и зависимости, ошибки.
- Вход сети один в один с симулятором — [contract/parity.md](../../contract/parity.md).
