# Сборка и запуск

[← Назад](../README.md) · [Документация](../README.md) › Запуск

Как собрать pack и запустить бой, где лежат результаты, честная сложность и обязательный мод.

- [Сборка pack](build.md) — Сборка не трогает игру: она только создаёт файлы в `build/<цель>/`
- [Запуск боя и результаты](run.md) — Launcher ставит собранный pack в игру, запускает один бой, ждёт итог, копирует результаты и убирает за собой только свои файлы
- [Смотреть бой сети](watch.md) — Настоящий бой, где нашей стороной командует цепочка уровней сети в помощнике, а стороной 2 — ИИ игры
