# Смотреть бой сети

[← Назад](README.md) · [Документация](../README.md) · [Запуск](run.md)

Настоящий бой, где нашей стороной (сторона 1) командует помощник: стратег расставляет, цепочка оперативник →
тактики → сеть отряда ведёт бой; стороной 2 — ИИ игры. Помощник работает в контейнере `snake-ai-trainer`
(`bridge/companion/`); игра и помощник общаются через файлы в папке игры ([bridge](../apps/bridge.md)).

## Запуск

Бой цепочки (Docker Desktop запущен, игра закрыта), скорость ×10 — на ×20 три сети не успевают за секунду боя
([мост, «Цепочка»](../apps/bridge.md#цепочка-оперативник--тактики--сеть-отряда)):

```powershell
python -m bridge.build nn-arena --own-ai net --deploy strategist --army-seed N --armies v3 --map ksl_plains_01 --speed 10 --timeout 1200
powershell -NoProfile -ExecutionPolicy Bypass -File bridge/launcher/watch.ps1 -NoBuild -Strategist default -StrategistTask hold -Chain -Graphics low
```

Бои М1–М3 одной командой (замок игры, метка игры пользователя, сборка и этот запуск, лог в `tmp/`) —
`game/battle/chain.sh`.

Что делает `watch.ps1`:

1. Без `-NoBuild` собирает арену, где нашей стороной командует помощник (`python -m bridge.build nn-arena --own-ai net`
   со своими `-Speed`, `-DecideMs`, `-TimeoutModelSeconds`, `-Skirmish`); бой цепочки с армиями и картой собирают
   отдельно (выше) и передают `-NoBuild`.
2. Запускает помощника в контейнере `snake-ai-trainer` (Python 3.12, torch 2.13 + CUDA 13.2; репозиторий в `/repo`,
   `-e PYTHONPATH=/repo`, папка игры в `/game`): `python -m bridge.companion --game /game --strategist ... --chain ...`.
   Его строки идут в то же окно: по строке на решение.
3. Проводит бой через [launch.ps1](run.md): честная нормальная сложность, настройки игрока
   возвращаются байт в байт, удаляются только наши файлы.
4. Бой кончается сам (победа стороны, предел боя или застой). Игра остаётся открытой ещё 30 с,
   чтобы увидеть конец, или пока вы её не закроете. Закрыть игру раньше тоже можно.
5. Останавливает помощника, удаляет файлы обмена из папки игры, копирует журнал помощника в папку
   прогона.

Параметры:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-Speed 1\|3\|10\|20` | 1 | Скорость боя (сборка без `-NoBuild`). Скрипт её держит: ускорение в игре возвращается назад |
| `-DecideMs` | 1000 | Время боя между решениями, мс (250–5000) |
| `-TimeoutModelSeconds` | 600 | Предел боя, с времени боя |
| `-LingerSeconds` | 30 | Сколько игра остаётся открытой после итога |
| `-NoBuild` | нет | Взять сборку, которая уже лежит в `build/nn-arena/` |
| `-Skirmish off\|game` | `off` (сборки) | Режим застрельщиков под мостом (сборка `--skirmish`; с `-NoBuild` берётся из сборки) ([bridge](../apps/bridge.md#режим-застрельщиков)) |
| `-Strategist default\|formula\|<чекпойнт>` | нет | Сборка с `--deploy strategist`: помощник расставляет нашу сторону стратегом (`--strategist`; `default` — из `net/config/strategist.json`) |
| `-StrategistTask hold\|destroy` | `hold` | Задача боя для стратега (уровня выше пока нет) |
| `-Chain` | нет | Сборка с `--own-ai net --deploy strategist`: после расстановки нашей стороной командует цепочка оперативник → тактики → сеть отряда (помощник `--chain`). Без него помощник отвечает только на расстановку, и наши отряды дальше стоят без приказов |
| `-ChainOp formula\|net\|<чекпойнт>` | `formula` | Оперативник цепочки: формула (сети на 40 групп пока нет; `run8` из `net/config/strategist.json` `operative_ckpt` собрана на 6 и не грузится) или путь к весам |
| `-ChainTactic formula\|net\|<чекпойнт>` | `formula` | Тактики цепочки: формула (как в симуляторе), сеть `run4` или путь |
| `-ChainGreedy` | нет | Все уровни цепочки берут лучший выбор (по умолчанию — по вероятностям, как цепочка симулятора) |
| `-Container` | `tww3-bai-companion` | Имя контейнера помощника (`agent-<задача>` для агента) |
| `-Graphics` | `BAI_GRAPHICS` | Набор графики на этот запуск (`launch.ps1 -Graphics`: `low`, `ultra`, `ultrafull`) |

Быстрая проверка: `-Speed 20 -LingerSeconds 0`.

Подпись над армией в игре (имя генерала в сценарии) — кто управляет стороной («ИИ игры (нормальная)», «Человек», …).
Её ставит сборка; свой текст — `--label-own` / `--label-enemy`. Игра идёт на русском (язык Steam), кириллица в шрифтах
есть. Имя ничем не читается: мост ищет отряды по `script_name`.

## Что печатает помощник

```
move   61  t   60.0 s  think   4.0 ms  turn  10.8 ms  | hold 1 attack 5 | lord attack spear_1, ...
```

Номер хода, время боя, время помощника (`think`), время от того, как помощник увидел состояние, до
записанного ответа (`turn`), сколько отрядов получили каждый вид приказа, первые приказы. Под цепочкой на каждое
решение ещё строка `chain sec N: raw .. op .. tac .. unit .. ms, inside k/7` (время по уровням и сколько отрядов в
своей области) и в секунду оперативника — `operative: g0 hold [...] -> [...] at (x, z)`.

## Результаты

`build/nn-arena/runs/<время>/`: как у любого прогона арены (`events.jsonl`, `status.json`,
`launch.json`) и ещё `companion.jsonl` — каждое решение помощника с приказами (под цепочкой — поле `chain`). В
`events.jsonl`: `nn_orders` (отданные приказы, ожидание ответа), `nn_miss` (нет ответа вовремя), `nn_deploy`,
`nn_deploy_check` (расстановка), в `result` — счётчики `nn_*` ([bridge](../apps/bridge.md#события)).

## Проверка в игре

Бои цепочки 07.11 — [мост, «Цепочка»](../apps/bridge.md#цепочка-оперативник--тактики--сеть-отряда). Первая проверка
самого обмена — прогон `20260930-204047`: ×20, арена 7 на 7 Империи, случайные приказы, нормальная сложность,
настройки возвращены.

| Что | Итог |
|---|---|
| Решения | 261 за 260,6 с боя (29 с реального времени); ответ на все 261, пропусков нет, битых файлов нет |
| Файлы | каждый раз переименование (`nn_write_mode: renamed`): в Lua игры есть `os.rename` и `os.remove` |
| От записи состояния до отданных приказов | реальное время: медиана 37 мс, 90% ≤ 43 мс, наибольшее 122 мс |
| Отдано приказов | 1502 (повторно отдаются только изменившиеся) |
| Выполнены ли | у 674 из 679 приказов «идти» и «отойти» точка приказа по данным самой игры (`ordered_position`) — это точка помощника (медиана разницы 0 м); наши отряды двигались в 77% замеров, каждый прошёл 360–730 м |
| Ошибки Lua | нет; игра закрыта, наш pack и файлы обмена удалены |

Один запуск (`20260930-203835`) уронил игру во время загрузки, до запуска нашего скрипта
(событий нет совсем; в отчёте о падении только код игры). Та же сборка в следующий раз прошла.
Причина неизвестна; помощник, пока ничего не происходит (загрузка, меню), ищет файл 10 раз
в секунду, а не 200.

На обычной скорости ожидание ответа — это ход помощника и до 100 мс, пока игра прочтёт
файл: с большим запасом внутри решения в 1 с. Под цепочкой на ×10 ожидание — медиана 51–53 мс настоящего времени.
