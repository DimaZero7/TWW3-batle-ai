# mem

[← Назад](README.md) · [Документация](../README.md) · [Приложения](../architecture/apps.md)

Чтение памяти игры через мод memreader Plus — **только в пробах** (сборка `--mem`), не в бою сети.
Код: `bridge/lua/apps/mem/`. Что подключено, границы, как запускать и что проверено — [чтение памяти игры](memreader.md).

## projectiles — снаряды в полёте

| Функция | Что делает |
|---|---|
| `check(mr, cfg)` | `{ok, why, version, plus_version, sites}`: мод загружен, у каждого места совпали байты (сборка игры) и сигнатура нашлась ровно один раз на том же адресе |
| `attach(mr, cfg)` | проверки, затем перехваты: `proj_update` (простой, только счётчик — функция идёт в потоке симуляции) и `ammo_left` (префикс патчера: читает отряд боя и его боезапас); `handle, status` или `nil, status` (проба идёт без памяти) |
| `handle.poll()` | один опрос списка снарядов (таймер пробы, 100 мс боя); путь к менеджеру ищет сам |
| `handle.drain()` | что накопилось с прошлого раза: `calls`, `spawn`, `state`, `gone`, `fly` (летящие сейчас), `records`, `ammo` (чтения перехвата), `chain` (путь к менеджеру), `discover`, `errors` |
| `handle.stats()` / `handle.detach()` | счётчики memreader / снять оба перехвата |
| `manager(mr, cfg, unit, off)` | менеджер снарядов: бой → мир → менеджер, мир должен ссылаться обратно на бой; бой — из `battle_global` или из отряда боя (`u_battle`) |
| `discover(mr, L, from, max)` | поля `from` (шаг 8), где лежит бой или мир (проверка ссылкой обратно); так найдено поле `u_battle` |
| `scanner(mr, L, max)` | разбор списка за один опрос (без игры — на поддельной памяти); ушёл — после `MISS_POLLS` (3) опросов без него |
| `address(mr, site)` | адрес места: `base + hi × 2²⁰ + lo` (числа Lua в игре 32-битные) |

## entities — бойцы отряда

| Функция | Что делает |
|---|---|
| `attach(mr, cfg)` | проверки (`projectiles.check`), префикс на `ammo_left`; `handle, status` или `nil, status`; в `status.dir_table` — векторы взгляда из таблицы игры |
| `handle.bind(name, unit)` | привязать скриптовый отряд: зовёт `unit:ammo_left()`, префикс видит боевой отряд; проверка: каждый боец вектора — этого отряда |
| `handle.unhook()` | снять перехват (после привязки) |
| `handle.poll(names)` | один опрос бойцов названных отрядов: `{c, tick, tick_end, cost, units = {name = {n, rows}}, new}`; строка — поля `ROW` |
| `handle.discover(from, to, n)` | смещения (шаг 8) у n бойцов `from`, где лежит указатель на бойца `to`: `{смещение = раз}` (только поля самого бойца) |
| `reader(mr, L)` | то же без игры — на поддельной памяти |

## hits — во что попал снаряд

| Функция | Что делает |
|---|---|
| `new(mr, L, ids, opts)` | `ids` — адреса бойцов → номер (из `entities`), `opts.units` — адреса привязанных отрядов |
| `H.who(p)` | у объекта «в теле» `p`: плоский список `{смещение, номер}` полей, где лежит указатель на известного бойца; первые `LEARN_N` (200) объектов читаются целиком (0…`MAX_OFF`), потом только выученные смещения; указатель на неизвестное тело — номер `−k` |
| `H.drain_other()` / `H.poll_other()` | новые «другие тела» `{k, адрес, отряд, hp, x, y, z}` (поля тела читаются один раз, не больше `OTHER_MAX` 16) / их здоровье сейчас |
| `H.offsets()` | выученные смещения (`nil`, пока учится) |

У `projectiles.scanner` два режима для этой пробы: `S.track` (место каждого летящего снаряда каждый опрос, в строке
«ушёл» — последнее) и `S.on_spawn(p, st)` (его ответ — 15-е поле строки «появился»).

## morale — мораль отряда

| Функция | Что делает |
|---|---|
| `attach(mr, cfg)` | проверки и привязка — `entities.attach`; без полей морали в настройках — `nil, status` |
| `handle.bind(name, unit)` | привязать отряд (как у бойцов) и проверить, что объект морали ссылается на этот отряд |
| `handle.poll(names)` | один опрос: у каждого отряда очки, цель, состояние, список слагаемых (номер, очки; `ok` — обход дошёл до конца и число узлов = счётчику), временные слагаемые, враги в касании, таймеры, байты флагов, поля отряда (`u_fields`) |
| `reader(mr, L)` | то же без игры — на поддельной памяти; обход списка — не больше `FX_MAX` (64) узлов |

## order — что отряд делает со строем

Верхнее поведение отряда и состояние его машины, отметки группы «на месте» и «перестроить», приказ и подприказ
группы, сколько бойцов с заданием хода, скаляр скорости. Пишет проба рукопашной с планом `memform` (`mem_form` каждые
0,1 с, [memreader](memreader.md#как-устроено)).

`cfg` — `config.mem` пробы: места и смещения из файла мест (по умолчанию `reverse/mem/sites_exe1103.json`, exe 03.11;
[reverse](../../../reverse/README.md)), в коде только имена.
