# Точки входа

[← Назад](README.md) · [Документация](../README.md) · [Приложения](../architecture/apps.md)

Точка входа связывает приложения в конкретный бой: подписывается на фазы,
запускает тик, вызывает адаптеры и сервисы, пишет телеметрию. Логики решений
в ней нет: каждая точка входа либо измеряет игру, либо записывает бой, либо передаёт бой помощнику. Код:
`bridge/lua/entries/`. Каждая точка входа — модуль с функцией `main(bm, config, globals)`,
её вызывает собранный скрипт. Входов шесть: [nn_arena](#nn_arena) (бой цепочки, бой человека),
[charge_probe](#charge_probe), [missile_probe](#missile_probe), [morale_probe](#morale_probe) (пробы механик),
[map_capture](#map_capture) (снять карту), [move_probe](#move_probe) (движение одного отряда).

<a id="nn_arena"></a>

## nn_arena — бой цепочки и бой человека

Сборка боя цепочки:

```bash
python -m bridge.build nn-arena --own-ai net --deploy strategist --army-seed N --armies v3 --map ksl_plains_01 --speed 10 --timeout 1200
python -m bridge.build nn-arena --own-ai net --deploy strategist --army-from-run <папка прогона> --map ksl_plains_01
```

Бои цепочки М1–М3 одной командой (замок, метка игры пользователя, сборка и [watch.ps1](../launch/watch.md)) —
`game/battle/chain.sh`.

Без `--timeout` сборка даёт 600 с игры. Файл боя пишет `sim/arena.py`: без армий — арена `sim/config/arena.json`
(пустая ровная карта MP Crossroads (flat), у каждой стороны лорд, 4 копейщика и 2 лучника Империи, фронты армий в
350 м); с `--army-seed` — бой генератора армий `sim/armies` (`generate.battle(N)`, схема `--armies`); с
`--army-from-run` — армии и расстановка старого прогона (`game/arena/army_from_run.py`); с `--map` — снятая карта
`sim/maps/<имя>/` и её зоны расстановки (`sim/maps/__init__.py`). Сторону 2 всегда ведёт общий боевой ИИ игры.
Обороняется сторона, которая побеждает по таймауту (`--own-role`, [нападающий и защитник](orders.md#нападающий-и-защитник)).
Нашей стороной командует:

- `net` — **цепочка** в помощнике вне игры: каждые `--decide-ms` (1 с) состояние уходит помощнику, его приказы
  (оперативник → тактики → сеть отряда, ответ со строкой `mode chain`) возвращаются и отдаются нашим отрядам
  ([bridge](bridge.md), [смотреть бой сети](../launch/watch.md)); ИИ игры атакует (по умолчанию). События
  `nn_orders`, `nn_miss`; `nn_sample` пишется как всегда. Мост выключает режим застрельщиков у наших отрядов
  (по умолчанию; `--skirmish game` — не трогать) ([bridge](bridge.md#режим-застрельщиков));
- `human` (цель сборки `human`) — нашей стороной командует человек, скрипт приказов не даёт; к записи
  добавляется [observer_adapter](telemetry.md#observer_adapter) (места бойцов — каждые `--soldiers-every` тиков)
  ([бой, который играет человек](../launch/run.md#бой-который-играет-человек)); `--live-label` — разметка вживую
  ([battle](battle.md#разметка-вживую)); `--free-speed` — скрипт не держит скорость, пауза и смена скорости за
  человеком (решения и опросы идут по времени боя, пауза их останавливает).

Расстановка: без `--deploy` фаза расстановки кончается через 1 с (отряды стоят, где их ставит файл боя). С
`--deploy strategist` нашу сторону в фазе расстановки ставит стратег помощника, у файла боя — зоны
стратега 1200 × 360 м ([мост, «Расстановка стратегом»](bridge.md#расстановка-стратегом)); события `nn_deploy`,
`nn_deploy_check`. У человека с `--live-label` расстановка — как обычно в игре, до его «Начать бой».

Каждую секунду `nn_sample` — все отряды обеих сторон (полная сводка):

| Поле | Что это |
|---|---|
| `n`, `side` | Скрипт-имя отряда (`own_lord`, `enemy_spear_1`, …) и сторона |
| `x`, `z`, `b` | Место, м, и направление, ° |
| `men`, `hp` | Живых бойцов, доля здоровья |
| `mp`, `ms` | Мораль из CCO: `MoralePercent` и `MoraleState` |
| `r`, `s`, `w` | Бежит, разбит, колеблется |
| `m`, `mv`, `f` | В рукопашной, идёт, бежит бегом |
| `a`, `fire` | Стрел осталось, стреляет ли сейчас |
| `t` | Текущая цель (скрипт-имя отряда) |
| `fat`, `k` | Усталость, убито врагов |
| `ox`, `oz` | Заданная позиция |
| `lf`, `rf`, `bf` | Угроза левому флангу, правому, тылу |
| `sv` | `unit:strategic_value()`: оценка силы отряда игрой сейчас |
| `pcr`, `phr` | CCO `PercentCasualtiesRecently`, `PercentHpLostRecently`: доля бойцов / здоровья, потерянная за последние 4 с |
| `mge` | CCO `MoraleGreatestEffect`: локализованный текст эффекта, сильнее всего влияющего на мораль (нет, если пусто) |
| `sk` | Режим застрельщиков включён сейчас (`unit:is_behaviour_active('skirmish')`); только у отрядов, у которых он есть. С `config.skirmish = 'off'` (по умолчанию у сборки `nn-arena`) мост его выключает ([bridge](bridge.md#режим-застрельщиков)) |

В самой записи ещё `bop` — CCO `BattleRoot.BalanceOfPowerPercent`, полоска сил вверху экрана для
союза игрока, — и `bop_side`, этот союз как номер нашей стороны (`bm:get_player_alliance_num()`;
он же в `ready` вместе с CCO `BattleRoot.PlayerAllianceContext.Id` как `player_alliance_cco`). Каждое
значение читается под `pcall`: чего игра не дала, того в записи нет. Они нужны для сверки правил разгрома
армии и морали симулятора и в состояние помощника не попадают.

Конец боя — последний снимок `nn_final` и `result`: исход, бойцы и здоровье сторон, счётчики моста `nn_*`.
Для анализа годятся только бои на нормальной сложности ([честная сложность](../launch/run.md#честная-сложность)).

## charge_probe — зонд рукопашной (одна механика, игра и симулятор одинаково)

Сборка: `python -m bridge.build charge-probe --probe-plan charge|hit|move --probe-battle N [--mem] [--kv ...]`; все бои
плана подряд: `python -m game.probe.charge_probe run --plan charge|hit|move [--battles 1,2]` (сборка и `launch.ps1`
для каждого); по бою на план с замком игры, `--mem` и лёгкой графикой — `bash game/probe/run.sh <план> [<план> ...]`.
Полный список планов — `PLANS` в `game/probe/charge_probe.py` (сборка берёт его оттуда); ниже — основные.
MP Crossroads (flat), 2–5 полос в 240 м друг от друга. В полосе нападающий и цель в `gap_m` друг от друга
(фронт к фронту); все под скриптом и бесстрашны. Приказ нападающему: атака бегом (`attack_run`), атака шагом
(`attack_walk`), приказ движения бегом в точку в 5 м за фронтом цели (`move_run`), повторный натиск
(`recharge`: через 10 с касания — бегом на 40 м назад, затем снова атака), выход из боя (`withdraw`: через
10 с касания — бегом на 150 м назад, приказ больше не меняется) или сценарий (`script`: в заданные секунды
приказ «лицом» на месте — `goto_location_angle_width` с новым направлением — или движение к точке; повороты).
Нападающий может включить свою способность через `a_ability_after_s` после касания (`a_ability`: Foe-Seeker).
`men_all_s`: места бойцов нападающего каждые `men_ms` с начала, где бы ни был враг; с `men_all_tg` — ещё места
бойцов цели и дополнительных отрядов полосы (план `artillery`: кто где погиб в строю за 150 м от орудий). Цель стоит и в первую секунду
касания получает приказ атаковать нападающего (`stand`), стоит и приказов не получает (`hold`: упор
копейщиков), атакует сама (`both`) или стоит спиной (`rear`). У полосы может быть лорд за целью, который в
секунду касания включает способность (Stand Your Ground) или нет (контроль). Не используемые лорды стоят далеко.

Планы: `charge` — 8 боёв (мечники на кланкрыс в четырёх приказах; кланкрысы на копейщиков в упоре, шагом,
со спины и на мечников; генерал и военачальник с разбега; копейщики на рабов-копейщиков с 150 и с 20 м —
скорость натиска); `hit` — 2 боя (мечники, большие мечи, копейщики со щитами на рабов без брони,
флагелланты на кланкрыс; кланкрысы-копейщики на копейщиков Империи с генералом за ними: в первом бою он
включает Stand Your Ground в секунду касания, во втором — нет); `move` — 2 боя: повороты
(копейщики «лицом» на 90° и обратно, потом на 180°; копейщики бегом в точку 150 м позади и 120 м сбоку;
Генерал и Варлорд «лицом» на 180° и 90°, потом бегом в точку позади; отсчёты 0,25 с, места бойцов) и выход
из боя (мечники и копейщики уходят через 10 с касания, их догоняют кланкрысы с приказом атаки или кланкрысы
стоят; Генерал рубит кланкрыс и через 50 с включает Foe-Seeker).
`syg2` — 2 боя (кланкрысы-копейщики на копейщиков Империи с генералом, который включает Stand Your Ground, когда
центры в `lord.at_m`, та же пара без него; флагелланты и мечники на кланкрыс; кланкрысы на держащих флагеллантов);
`pair` — 1 бой (кланкрысы-копейщики атакуют копейщиков Империи с 80 м, 240 с; копейщики держат, отвечают или
`push`: приказ движения шагом к точке в `push_m` 60 м впереди, сквозь нападающего); `fatleave` — 1 бой (обе
стороны атакуют с 3 м без разбега, и фронт 60 м против 15 м — `a_w` / `t_w`; трое уходят от держащих кланкрыс).
`skirmish` — 2 боя по 10 полос (ряды по 5 в 200 м друг от друга, ряды в 600 м; во втором бою ряды меняются):
режим застрельщиков. Стрелок стоит (цель полосы, `target_mode = 'skirmish'`: на месте, стрельба по выбору,
при старте режим включён или выключен по `t_skirmish`, событие `probe_skirmish` — был ли режим до того и стал ли;
на старте — атака стрелами шагом на нападающего, как мост целит стоящего стрелка), пехота атакует его бегом с
60 м, 90 с: пращники-рабы и Ночные бегуны (их догоняют мечники), лучники, арбалетчики и аркебузиры Империи (их
догоняют кланкрысы), каждый с режимом и без. В строке стрелка — стрелы, флаг стрельбы, нанесённый урон и `sk`;
места бойцов — каждую 1 с в 200 м. Разбор: `python -m game.probe.charge_probe skirmish [папки] [--sim]` — с какого
расстояния стрелок начинает уходить, куда и как быстро, стреляет ли на ходу, сколько стрел успел, догнали ли, потери
обоих; `--sim` — рядом двойник в симуляторе.
`skirmish2` — 2 боя по 12 полос: что включает режим застрельщиков. Пращники-рабы, лучники и арбалетчики с
режимом (стоят, как в `skirmish`); виды полос: `pass` — пехота врага (фронт 12 м) бежит мимо стрелка, центр в
30 м сбоку (край ~9 м), к точке в 100 м за его фронтом и его не атакует (режим нападающего `pass`); `neighbour`
— пехота атакует соседа стрелка (отряд его стороны, фронт 20 м, центр в 30 м сбоку; режим `attack_t2`, ширина
соседа — `t2_width`); `control` — пехота атакует самого стрелка; по 60 с; `long` — быстрая пехота (кланкрысы
4,2 м/с, за пращниками флагелланты 3,6) гонится за стрелком 120 с в своей длинной полосе (~1080 м): разгон и
от чего он (усталость, флаг бега). Короткие полосы — 2 ряда по 5 мест в 150 м, длинные — 3 своих столбца; во
втором бою полосы переставлены. Таблица `skirmish` делит их по стрелку и виду; «догнали» — по флагу рукопашной
самого стрелка; у `long` — скорость, доля бега и усталость по 30 с.
Усталость и упор: план `fatrun` (режим `laps`: кланкрысы 180 с бегут или идут по восьмиугольнику
радиусом 40 м вокруг своего места, потом стоят на месте до конца полосы; ранг пишется в сценарий (`a_rank`);
`t_near_m` — в миг остановки стоящий враг ставится в столько метров перед отрядом) и `brace` (кланкрысы натиском на
держащих копейщиков под углом `a_side` 0 / 30 / 60 / 100° к их взгляду, здоровье каждые 0,1 с); их разборы — в архиве
(`tmp/old-build/fatcharge/`).
Новые отряды до симулятора (`game/probe/unit_probe.py`,
[план](../../../sim/evidence/newunits/plan.md)): планы `ratling` (Пушка Крысолинга
стреляет по стоящим мечникам с 60 / 100 / 135 м, по копейщикам со щитом, с половиной расчёта, по Генералу),
`suppress` (мечники идут шагом и бегом на стреляющую или молчащую Пушку: скорость под подавлением), `suppress2`
(Пушка замолкает через 25 / 15 с — `t_stop_fire_s`: сколько держится подавление после последнего выстрела), `censer`
(кадила и монахи на мечников и копейщиков, уход кадил, бегство, алебардисты на штурмкрыс), `wolfrats` (бег и
разворот крысоволков, натиск со 120 м, на упор, в тыл, на Генерала, повторный, погоня за бегущими и контроль
кланкрысами), `wolfpoison` (крысоволки с ядом и без; уход, мечники стоят или догоняют), `hitslow` (кланкрысы без
щитов идут шагом и бегом на аркебузиров и арбалетчиков, контроль — молчащие аркебузиры: тормозят ли сами попадания) —
по 2 боя (`suppress2` — 1). В полосе
можно назвать любой отряд Империи или Скавенов по ключу базы: паспорт из `sim/config/units.json` или
`sim/data/probe-units.json` (пишет `py -3.14 -m sim.passports.units --units …`).
`card_rows` — в строках обоих отрядов `cs`: текущие значения карточки (лидерство, скорость, атака и защита,
урон оружия и стрельбы); у нападающего полосы `shoot` — строка стрелка (боезапас, флаг стрельбы, урон).
Разбор: `python -m game.probe.unit_probe [папки]` — по плану и виду полосы среднее (мин–макс); `--sim` — рядом
двойник в симуляторе на тех же полосах (игра | симулятор).
Режим нападающего `cast` (в заданные секунды `perform_special_ability(ключ, цель)`, событие `probe_ability`) и
`winds_ms` (ветра обеих сторон каждую 1 с, `probe_winds`; `apps.battle.winds`) в Lua есть; планов магии сейчас нет.
С `--mem` — бойцы и снаряды из памяти игры (планы `memmelee`, `memshot`, `memform`; [memreader](memreader.md)).

Каждые 0,5 с `probe_sample` по полосе: бойцы, здоровье (CCO `HealthValue`), флаги рукопашной, движения и
бега, место, направление, убитые, усталость, ключи статусов (CCO `StatusList`: `braced`, `melee`…) у
нападающего, цели и лорда; `probe_contact` (первое и второе касание), `probe_phase` (повторный натиск),
`probe_ability`; каждую 1 с, пока отряды ближе 60 м и до 30 с после касания, — места всех бойцов обоих
(`probe_men`, CCO `ManList`). Полоса кончается через `fight_s` после первого касания. Разбор:
`python -m game.probe.charge_probe report [--sim]` — скорость на подходе (последние 30 и 10 м), здоровье
цели и нападающего за 0–1, 0–2, 0–5, 5–15, 15–30 с после касания и в секунду с 15 с, бойцы в 1,5 / 2,5 /
3,5 м от врага; `--sim` — тот же разбор симулятора на тех же полосах (те же места и приказы, 8 копий);
окна «0–…» начинаются с отсчёта перед касанием (удар в отсчёте касания входит). `turns [--sim]` — повороты
(секунды до 10° от нового направления, скорость центра по секундам, сохранили ли бойцы свои шеренги);
`exits [--sim]` — выход из боя (сколько уходящий в рукопашной, его убитые и урон врагу за 0–24 и 26–50 с
после приказа) и усталость лорда со способностью. Симулятор не знает приказа «лицом»: близнец ставит
направление сразу. Итоги идут в `_why` симулятора (`sim/config/sim.json`, [симулятор](../../../sim/README.md)).

<a id="missile_probe"></a>

## missile_probe — проба стрельбы

Сборка: `python -m bridge.build missile-probe --mprobe-plan dist --mprobe-battle N [--mem] [--kv ...]`; все бои плана:
`python -m game.probe.missile_probe run --plan dist [--battles 1,2] [--mem]`; разбор —
`python -m game.probe.missile_probe report [папки] [--sim]` (`--sim` — двойник в симуляторе на тех же полосах).
Одна механика стрельбы в полосах далеко друг от друга, все под скриптом и бесстрашны: стрелок (`fire` — стрельба
по выбору без приказа, `attack` — приказ атаки на цель, `hold` — не стреляет, контроль; `s_move_fwd` / `s_move_lat` —
стрельба на ходу) и цель в `d` м под углом `t_angle` к взгляду стрелка, повёрнутая на `t_rot` (0 — фронтом, 90 — флангом,
180 — спиной). Цель стоит (`stand`), шагами подходит до первого выстрела (`step`: проверка дальности) или идёт в точку
(`move`). `reform_men` — цель при стольких бойцах перестраивается сдвигом на 5 м со своей шириной; `reorder_s` —
повторный приказ атаки (сброс прицела); `friend` — свой отряд в `friend_fwd` / `friend_lat` от стрелка (линия огня
мимо своих; с `friend_engage` — в рукопашной с целью, с `friend_fire` — второй стрелок), в отсчётах — `f`.
`soldiers_every_s` — места бойцов стрелка и своего (`probe_soldiers`). Каждые `tick_ms` `probe_sample`: у стрелка
боезапас, бойцы, флаг стрельбы, место, направление, движение; у цели бойцы, здоровье (CCO `HealthValue`), место.
Полоса кончается, когда кончились стрелы или цель, стрелок не стрелял `idle_s` после первого выстрела или через
`max_s`. Планы: `dist`, `arc`, `range`, `targets`, `shield`, `moving`, `rank`, `thin`, `pistol`, `moving2`, `lof`,
`newdist`, `starsmove`, `meleefire`, `hglof`, `rangenew`, `lofab`, `lofthresh`, `lofheight`, `rangestand`, `lonerank`,
`shots`, `stacked`. С `--mem` — снаряды в полёте из памяти игры ([memreader](memreader.md#снаряды-в-полёте)).

<a id="morale_probe"></a>

## morale_probe — проба морали

Сборка: `python -m bridge.build morale-probe --morale-plan flank --morale-battle N [--mem] [--kv ...]`; все бои плана:
`python -m game.probe.morale_probe run --plan flank [--battles 1,2]`; разбор —
`python -m game.probe.morale_probe report [папки] [--sim]`.
Одно слагаемое морали в полосах далеко друг от друга: в полосе несколько отрядов поставлены скриптом и держатся им (без
ИИ); отряды из `config.fearless` бесстрашны (у другой стороны слагаемого мораль своя). Полоса — список шагов
(`lane.steps`), каждый срабатывает раз, когда случился его повод и прошло ещё `delay_s`: `go` (старт), `contact`
(первая рукопашная роли `of`), `rout`, `rally`, `waver`, `step` (сработал шаг номер `of`). Что делает шаг: `attack` /
`attack_walk`, `shoot`, `move` / `move_walk`, `halt`, `stop_fire`, `kill` (движок убивает долю живых бойцов:
`unit:kill_number_of_men`; его убитые идут в потери за бой, но не в «недавние потери»), `shadow` (держаться в `d` м от
роли), `ability` (способность на себя: Stand Your Ground, Rally), `end`. Каждые `tick_ms` `probe_sample`: у каждой
роли место, направление, бойцы, здоровье, рукопашная, бежит / колеблется / разбит, CCO `MoralePercent`, `MoraleState`,
`MoraleGreatestEffect`, `PercentHpLostRecently`, бег, стрельба, действующие эффекты (`fx`), `hid`, `v` и, с `lane.card`,
`arm` (броня с карточки). Планы: `flank`, `charge`, `secure`, `shoot`, `rally`, `strong`, `penitent`, `aura`,
`strong2` (шкала сильного врага, 6 врагов, 120–30 м), `rally2` (часы сбора), `timer`, `hyp` (гипотезы о морали: 4 боя
по 1–6 полос в столбец вдоль z, 0,25 с: таймер колебания и сбор у ранга 0 и 9 — ранг пишется в сценарий, слабый враг у
бегущего, фронт врага 12 / 60 м при сборе, удар с тыла и во фланг, ровные схватки, бегущие свои и чужие вместе), `mem`
(мораль из памяти игры, `--mem`; [memreader](memreader.md#мораль-отряда)), `runners`.

<a id="move_probe"></a>

## move_probe — движение одного отряда

Сборка: `python -m bridge.build move-probe --plan hamlet`. Сценарий
`move_probe.xml` на **The Moorlands Route** (`catchment_03`): отряд
`probe_spears` (копейщики Империи) и далёкий генерал `far_general`, которого
держит скрипт; другой файл боя — `--scenario` (планы `ksl_*` — карты Кислева, обход реки и броды).

План `bridge/config/move-plans/<имя>.json` — список заходов:

- `shape` — перестроиться на месте в другую ширину;
- `traverse` — один обычный приказ в дальнюю точку.

Заход: телепорт в старт, 2 с на успокоение, один
`goto_location_angle_width`, затем каждую секунду `move_sample` (движение
отряда и позиции всех бойцов в дециметрах) до `leg_end` с причиной
`arrived`, `stopped`, `stuck` или `timeout` (`apps.navigation.services`).

Разбор: `python -m game.probe.move_probe <events.jsonl> <папка>` — по заходу причина конца, время, путь, крюк, строй;
рисунки строя и путей.

<a id="map_capture"></a>

## map_capture — сбор карты

Сборка: `python -m bridge.build map-capture --step 3 [--features] [--nodes] [--window MIN_X MAX_X MIN_Z MAX_Z]`.
Сценарий `map_capture.xml`, файлы с префиксом `tww3_bai_map_capture_`.

1. Через 3 с после загрузки: пауза, `ready.xml`, рамка радара (`frame`,
   `corner`), сетка (`grid_begin`).
2. Пачки по 4096 клеток → `grid.csv`:
   `ix,iz,x,z,height,clear,ground,inside_radar`. С `--nodes` — в кратных шагу точках (узлы высот движка), а не в
   центрах клеток.
3. С `--features`: взять оба отряда под контроль, завершить расстановку на
   ×20, поставить паузу, затем здания (`building`), список CCO
   (`structure_context`) и достижимость клеток для обеих сторон
   (`reach_side_1`, `reach_side_2` в CSV).
4. `probe_done` или `probe_error`.

Карту целиком (сборка с `--nodes --features`, запуск и сведение в `sim/maps/<имя>/`: `heights.npz`, `trees.npz`,
`passable.npz`, `meta.json`) снимает `python -m game.maps.map_grid capture --name <имя>` (`game/maps/map_grid.py`), один
раз на карту; не во время игры пользователя. Без снятой карты помощник вход сети не строит.

## Общее

- **Бой всегда заканчивается сам.** Три предохранителя:
  срок в реальном времени `deadline_s` (`battle.deadline`, результат `deadline`);
  застой — никто не получает урона `stall_ms` игрового времени, по умолчанию
  10 минут (`battle.services.new_stall_detector`, результат `stalled`);
  лимит launcher = 240 с на загрузку + срок боя. Параметры сборки:
  `--deadline`, `--stall-minutes`.

- **Скорость.** Когда исход решён и отряды бегут, движок сам сбрасывает
  скорость до ×1. `battle.speed_guard` каждые 0,5 с возвращает заданную
  скорость до фазы `Complete` и пишет `speed_restored` (проверено 27.09.2026
  на ×20: сброс 1 → 20 сразу после `result`). Пауза (скорость 0) не трогается.
  С `--free-speed` (бой человека) скорость не держится.

- Защита от повторной загрузки: глобальный флаг `tww3_bai_<точка входа>`
  (например, `tww3_bai_nn_arena`, `tww3_bai_map_capture`).
- Все колбэки — через `errors.guard` ([ошибки](../architecture/error_handling.md)).
- Проверка без игры — дымовой тест `bridge/tests/test_bridge_smoke.py`: сборка пака (бандлер и проверка синтаксиса
  Lua) и ответ помощника на записанный документ.
