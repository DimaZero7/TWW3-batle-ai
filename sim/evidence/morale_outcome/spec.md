## Правило игры
| что | игра (адрес) |
|---|---|
| окна потерь | кольца ячеек по 1 с: 4 и 60 (`142f3125c`); раз в целую секунду сдвиг и обнуление новой ячейки (`142f5a040`); доля = урон здоровью последних 3 / 59 с / начальное здоровье (+0x80), держится секунду |
| что в окне | урон здоровью от удара с отрядом-источником (любой вид: рукопашная, снаряды, яд, столкновения; свой огонь тоже; `143260a34`) |
| итог схватки | каждый тик (`142f55cd4`): us = полученный за 60 с / макс. своё здоровье за 60 с; them = нанесённый за 60 с (кому угодно) / Σ макс. здоровья врагов списка за 30 с |
| пороги | больше из долей ≤ 0,1 → ровно; меньшая/большая < 0,3 / 0,6 / 0,8 → +8 / +6 / +3 (выигрывает), −8 / −3 / 0 (проигрывает); иначе ровно |
| список врагов | раз в секунду: враги в рукопашном касании + цели верхней задачи с флагом атаки у любой из сторон (стрельба FIRE_STATE); прочие уходят |
| бегущий | 0 (`14301ec44`) |

## Было в симуляторе → стало
| | было (подогнано) | стало |
|---|---|---|
| перевес | (урон нанесённый + 1) / (полученный + 1), затухание 30 с (`recent_s`), рукопашная + снаряды | доли здоровья за 60-с кольцо (`outcome`) |
| пороги | `combat_ratio` 1,5 / 2,5 / 4 (выигрыш), 1,0 / 2,5 (проигрыш), «ровной» зоны нет | 0,1 / 0,3 / 0,6 / 0,8 из кода; «чуть проигрывает» = 0 |
| ворота | `combat_lost` 0,1 (своя потеря / потеря врага за бой) | порог 0,1 — на большей из долей за 60 с |
| когда считается | в рукопашной, стреляет или по нему стреляют (`in_combat`); у стрелка — только обмен со своей целью (`combat_shooter`) | список врагов: касание (`touch`, с погоней) или один стреляет по другому; кто вне списка — не в знаменателе |
| одиночка | всегда −3 в рукопашной (`single_combat`) | как отряд (в коде нет ветки для одиночки) |
| окна потерь | скользящие ровно 4 с и 60 с, каждый шаг | кольца 1-с ячеек: 3 и 59 последних целых секунд, обновление раз в секунду |
| `combat_even`, `recent_of_current` | выкл. / false | убраны (в коде нет) |

Приближённо: (1) список по задачам — через то, что считает симулятор: касание и «стреляет по» (`firing`, `m_target`);
задачи построения лицом к цели (REFORM_STATE, `143ae43b0`) и задача на список целей (`14391ac88`) не моделируются;
(2) враг, ударивший между секундами, в списке не появляется (в игре — со здоровьем 0 до секунды: на итог не влияет);
(3) макс. здоровье — как здоровье сейчас + потерянное в окне (у регенерирующих чуть выше игры).
