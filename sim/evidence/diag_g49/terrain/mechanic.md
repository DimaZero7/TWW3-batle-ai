# Высота и склоны в бою: правила игры и план переноса

Разбор 28.10.2026, только высота (холмы, склоны). Лес, вода, непроходимое, здания — не разбирались.
Откуда: **разбор** — статический разбор программы игры (подробности, адреса и выдержки — только в
`reverse/notes/terrain.md`, разделы указаны §); **база** — `config/nn/game_rules.json`; **сообщество** — блог CA
«Feature Focus #1: Elevation», academy.totalwar.com, вики. Уверенность: **В** — код прочитан целиком,
**С** — код прочитан, смысл одного поля по контексту, **Н** — догадка.

## Главное в пяти строках
1. Высота меняет **урон**, а не шанс попасть: в рукопашной ±30 % уже при перепаде 1 м, у снарядов ±30 % при 40 м.
2. **Скорость**: в гору ×1/(1+уклон), под гору ×(1+|уклон|), не больше ×1,5.
3. **Усталость** на подъёме считается странно (так в коде): 5–10 % — вдвое меньше, 10–20 % — как на ровном,
   > 20 % — в 1,5 раза больше.
4. **Стрельба**: дальность высота не меняет (меряется по земле, по плоскости); высота меняет угол вылета → точность,
   урон, и холм закрывает линию огня (луки переходят на навес 45°, пули не стреляют).
5. **Мораль**: +10, если отряд на 10 м выше каждого врага в 120 м.

## 5. Что даёт игра о высоте (для моста)

- `bm:get_terrain_height(x, z)` уже работает в нашем мосте (`docs/ru/game/map/heights.md`). По коду: высота земли —
  **регулярная сетка с билинейной интерполяцией**, шаг по снятой карте Кислева — **2 м** (С, одна карта). Значит,
  опрос сетки 2 м по узлам даёт землю **точно**, а не приближённо. Lua возвращает максимум из земли и второй сетки
  (Н: уровень воды) — на суше то же самое.
- Скорость опроса уже замерена: 1 км² с шагом 2 м — 262 тыс. точек за 1,9 с на паузе расстановки
  (`docs/ru/game/map/sampling.md`). Рельеф в полевом бою не меняется → **снимать один раз** при расстановке.
- Запросов «линия огня» / «линия взгляда» в Lua **нет** (на поле боя только `get_terrain_height`, `is_area_clear`,
  `ground_type`; у отряда `is_visible_to_alliance`). Линию огня по земле считаем сами по снятой сетке.
- Высоту каждого бойца мост уже может брать: y из позиции = земля под ним.

## 6. План переноса

### 6.1 Симулятор (`tools/nn/sim`), по порядку пользы
1. **Поле высот**: тензор сетки 2 м на бой (из снятой карты или сгенерированный рельеф для учений), билинейная
   выборка `h(x, z)` на видеокарте; y бойца = h под ним.
2. **Урон рукопашной** × (1 − clamp(0,3 Δh, ±0,3)) по паре бойцов (Δh — защитник − бьющий; в натиске Δh / r²;
   very_large — нет; strider-бьющий без штрафа). Дёшево: Δh по уже найденным парам.
3. **Скорость**: g по направлению шага на длину L; × 1/(1+g) или × min(1,5; 1−g). L до пробы взять радиусом тела.
4. **Усталость**: множитель 0,5 / 1 / 1,5 по g (порог 0,05 / 0,1 / 0,2), с отбрасыванием дробной части.
5. **Снаряды**: Δh в баллистике (угол θ → точность, «не долетает»), урон × (1 + clamp(0,3 Δh / 40, ±0,3)).
6. **Линия огня по земле**: дуга снаряда хордами по ~16 м против сетки высот — 3 луча отряда (≥ 2 чистых) →
   навес 45° для луков / отказ для пуль; проверка пути бойца. Самая дорогая часть — делать последней.
7. **Мораль**: +10 за 10 м выше всех врагов в 120 м.
Смена механики меняет версию симулятора (`VERSION_FILES`) — сказать в отчёте.

### 6.2 Слой сети (карта зоны 30×30 по 8 м, `tools/nn/unit/zmap.py`; новые слои — в конец)
- `height` — (высота центра клетки − высота под моим отрядом) / 20 м, обрезать в [−2, 2]. Относительная высота, а не
  мировая: мировая Y на разных картах разная (Кислев 190–270 м), а правила зависят только от разницы.
- `slope_fwd`, `slope_right` — уклон земли в клетке вдоль «вперёд» и «вправо» повёрнутой рамки (м/м, обрезать
  ±1). Скорость зависит от уклона по направлению хода — два компонента дают его для любого направления.
- В строку отряда (точные числа, не на карте): высота отряда-цели/соседа относительно меня (м / 20) и уклон под
  моим отрядом. Рукопашная насыщается уже при 1 м — клетка 8 м этого не покажет, нужна точная разница в строке.
- Не делать слой «линия огня закрыта» сразу: сеть может вывести её из `height`; добавить, только если обучение
  покажет, что не выводит.
- Сетку высот под карту зоны брать билинейно в центрах клеток (8 м) из сетки 2 м.

### 6.3 Мост
- Снятие сетки высот 2 м по узлам один раз на паузе расстановки (сборщик уже есть, `src/apps/map/`), рамка — поле
  боя; запись рядом с записью боя, чтобы симулятор и сеть брали ту же карту.
- Проверить узлы: опросить 2 точки внутри клетки и сравнить с билинейной формулой по 4 узлам (подтвердит шаг 2 м и
  интерполяцию на второй карте).

### 6.4 Проба в игре (минимум, 4 коротких сценария, ~10 мин; карта с холмом, где уклон известен по снятой сетке)
Обязательный набор пробы (рейтинг / золото пар / гибель лорда) здесь не нужен — пробы механик.
1. **Скорость**: один пехотный отряд бегом по прямой в гору и с горы по участку с ровным уклоном ~0,1 и ~0,3;
   сравнить скорость с 1/(1+g) и 1−g. Проверяет и длину L (если скорость меняется раньше перелома склона).
2. **Усталость**: тот же отряд бегом 60 с по уклону 5–10 % и по ровному. Код говорит: на уклоне устанет **меньше**
   (+2 вместо +4 за тик). Самое неожиданное правило — его проверить первым.
3. **Рукопашная**: два одинаковых отряда мечников, один стоит на склоне выше (≥ 1–2 м перепада по фронту), второй
   атакует снизу; и зеркально. Ожидание: отношение потерь ~1,86 (только урон, шанс попасть тот же).
4. **Стрельба**: один отряд лучников стреляет по стоящей пехоте с 40 м выше и с ровного на той же дальности по
   земле. Ожидание: урон ×1,3, точность выше на ~8–10 % (угол); дальность та же.
Пробы не меняют обучение; запускать на пустой машине, графика на RTX, «Нормальная».

## 7. Чего не знаем
- Толчок тел при натиске под гору (сбивание от скорости) — функция не найдена.
- Какие снаряды помечены «без высоты» (вероятно взрывные/магические).
- Длина L в уклоне (по смыслу радиус тела) — закроет проба 1.
- Шаг сетки 2 м проверен на одной карте.
- Видимость (туман войны) через холмы — отдельная механика, в симуляторе её нет вовсе.
