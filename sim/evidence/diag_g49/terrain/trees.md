# Деревья: перехват снарядов, стволы в строю, где лежат — правила и перенос

Разбор 28.10.2026. Откуда: **разбор** — статический разбор программы игры (адреса и выдержки — только в
`reverse/notes/trees.md`, разделы §); **данные** — `vegetation.pack` (`tree_metadata.txt`: радиус и высота тела каждой
модели дерева), `db.pack` (`projectiles`), список деревьев Кислева (уже извлечён: `docs/ru/game/map/vegetation.md`).
Уверенность: **В** — код прочитан целиком, **С** — смысл по контексту, **Н** — догадка.

## Главное
1. Каждое дерево — **вертикальный цилиндр** (ствол) от земли на всю высоту дерева; радиус = радиус модели ×
   масштаб, не больше 2,25 м. Крон как препятствия нет.
2. **Снаряд, задевший ствол, останавливается** (без урона). Но первые **~42 м полёта** любой снаряд деревья не
   замечает (поле `vegetation_ignore_time` ≈ 42 м / скорость снаряда) — поэтому стрелки из леса бьют наружу.
3. Особого «стрелять сквозь деревья» у лесных эльфов **нет**: у их стрел те же 42 м.
4. Стволы — препятствия и для бойцов (общая физика тел); «Следопыт» и «Сквозь деревья» проходят насквозь.
5. На Кислеве стволы тонкие (медиана 0,4 м) и редкие (одно дерево на 35 м²): строй почти не рвётся (~6 % мест
   задето), а пуля, летящая низко по лесу, встречает ствол в среднем раз на ~44 м пути.

## 3. Где лежат деревья — В
- Список деревьев — файл карты `*.tree_list.bin` в пакете плиток карты (Кислев: `ksl.tree_list.bin` в `tile074.pack`):
  модель, x, y, z, поворот, **масштаб**. Формат уже разобран и проверен (`docs/ru/game/map/vegetation.md`).
- Радиус и высота тела — `vegetation.pack` → `battleterrain/vegetation/trees/tree_metadata.txt` (таблица: модель,
  CollHeight, CollRadius). Тело = min(масштаб × CollRadius, 2,25 м); 0 → 0,85 м; высота = масштаб × CollHeight.
  Модели без строки тел не получают.
- Игра строит тела только для деревьев внутри рамки поля боя.
- Кислев: 5168 точек, **5159 стволов**, 3724 в лесу (лес 129 тыс. м²). Радиус: медиана 0,40 м (10–90 %: 0,26–0,50),
  максимум 1,10; высота: медиана 14 м. Плотность 0,029 на м², шаг ~5,9 м. Клеток 3 м со стволом — 26 %.
- Достать для другой карты: найти её `*.tree_list.bin` в пакетах плиток, привязать координаты (для Кислева: −3072 м
  по X/Z, +100 м по Y — подобрано по рельефу) и сверить высоту точек с `get_terrain_height`. Защиты здесь нет: это
  обычные данные пакетов. Скриптами игра список не отдаёт.

## 4. Перенос в симулятор (отряд — прямоугольник, лес — клетки 1–2 м)
Из списка стволов посчитать по клеткам:
- `trunk_λ` — «плотность перехвата»: Σ 2·(r_ствола + r_снаряда) / площадь клетки, только стволы выше пути снаряда
  (на 1–2 м — почти все). Перехват снаряда: P = 1 − exp(−Σ λ·длина пути по клетке) только на участке полёта
  после 42 м и ниже высоты стволов (для навеса — только последний отрезок); перехваченный снаряд урона не наносит.
  Брать стволы из списка карты (не метры «леса»: стволы стоят и вне него, §5); r_снаряда = 0. Без списка (другие
  карты): λ ≈ 0,02 /м для клеток «лес» — число Кислева, отметить как приближение.
- `trunk_share` — доля площади под «ствол + 0,4 м тела»: доля бойцов, стоящих не на своём месте (сдвиг ≤ 1 м), —
  для рукопашной на Кислеве можно не моделировать (~6 %).
- Движение и натиск: `trunk_hits_per_m` = Σ 2·(r + 0,5) / площадь (Кислев 0,052 /м) — сколько бойцов за метр пути
  встречает ствол; последствие (задержка, сбитый разбег) — после пробы.
- Слой сети: одна величина `trunk_λ` (или просто `forest` + число на карту), и только если пробы покажут, что
  перехват заметен.

## 5. Сверка с пробой 28.10 (build/diag_g49/ground, запуски 20261028-205237 / -205338)
Перехват посчитан по коду без подгонки: настоящие стволы Кислева (список + `tree_metadata.txt`) на линиях пробы,
лучники (стрела 45 м/с, `vegetation_ignore_time` 0,93 с), настильная дуга на ~110 м, 400 случайных пар
«стрелок — цель» по ширине строя (скрипт и выдержки — reverse/notes/trees/strip_check*.py).

| полоса (метры «леса» по типу земли) | проба: урон на выстрел к лугу | код, радиус снаряда 0 | код, + радиус 0,1 м | код без «первых 42 м» |
|---|---|---|---|---|
| 7 м | ×0,86 (−14 %) | −11 % | −14 % | −22 % |
| 11 м | ×0,87 (−13 %) | −19 % | −25 % | −55 % |
| 57 м | ×0,68 (−32 %) | −35 % | −47 % | −81 % |

- Сходится с правилом «ствол останавливает снаряд, первые ~42 м полёта — без деревьев»; радиус снаряда, судя по
  57 м, **не прибавляется** (−35 % против −32 %). Без «первых 42 м» расчёт втрое больше пробы — правило подтверждено.
- «Узкая полоса уже ~13 %»: стволы стоят и вне земли «лес» (на Кислеве 1446 из 5168), а земля «лес» не равна
  стволам. Поэтому для переноса нужен **список стволов**, а не метры леса по типу земли.
- Разброс между тремя лугами ×0,93–1,05 (одна битва на линию) — разница 11 м против расчёта в эти пределы входит.
- Скорость в лесу: пехота ×0,94 (правило ×1), рыцари ×0,69 (правило ×0,8 → лишние ×0,86). Лишнее — стволы:
  встреч со стволом на метр пути ∝ 2·(r_ствола + r_тела); у коня тело больше — потери больше. Сходится по смыслу
  с телами-стволами (§2); числа обхода из кода не выведены.
- Цель в лесу — 0 выстрелов: см. §6, это скрытность, не укрытие.

## 6. Скрытность: у нас прячутся почти все, симулятор это уже умеет — В
- В нашем составе (`config/nn/units.json`, 36 отрядов): **hide_forest у 31** (вся пехота, лорды, стрелки, крысоволки),
  **stalk у 5** (Охотники, Бегущие по канавам). В лесу прячется **любой** наш отряд.
- Врага, спрятанного в лесу, видно с `spot_dist_tree` 60 м × hiding_scalar (кланкрысы 0,8 → **48 м**, край строя —
  край строя); на открытой земле — 80 м (`spot_dist_scrub`). Стрелки на 100 м спрятанную цель не видят и не бьют —
  отсюда 0 выстрелов в пробе.
- **В симуляторе** (`tools/nn/sim/stealth.py`, `config/nn/sim.json` stealth, on = 1): скрытность и обнаружение
  есть — доля 85/75 %, 5 с до скрытности, 1,5 с запаса, зоркость × hiding_scalar край–край, +20 м первые 5 с,
  раскрытие стрельбой и рукопашной; скрытого не выбирают целью, не бьют, мораль его не считает, сеть видит его
  последнее место. **Но леса нет**: «прячущая земля» есть только у stalk (любая земля), hide_forest-отряды не
  прячутся никогда, зоркость — только «открытая» (80 м). Видимости по линии взгляда (холмы, лес) **нет**: кто не
  спрятан, виден всегда.
- Значит, «скрытность включена» и «видимости нет» — оба верно: включено прятание stalk-отрядов, а обзора через
  рельеф и лесного прятания нет. Для леса в симуляторе не хватает: слоя «лес» под бойцами (доля > 85 %) и зоркости
  `spot_dist_tree` (60 м) для цели, стоящей в основном в лесу.
