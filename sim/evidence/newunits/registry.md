# Новые отряды: реестр показателей против симулятора

Рабочий набор (решение пользователя): Империя — **аркебузиры** («Пистольеры», `wh_main_emp_inf_handgunners`) и
**арбалетчики**; скавены — кланокрысы (`clanrats_0`), кланокрысы с копьями и щитами (`clanrat_spearmen_1`), штормокрысы с
алебардами (`stormvermin_0`, паспорт уже есть) и с мечами и щитами (`stormvermin_1`), Бегущие ночью со звёздами
(`night_runners_0`). Бегущие ночью с пращами уже есть. Отложены: Бегущие по канавам (оба, Stalk). Конница не берётся.

Номера K / Б / Э — строки реестра `docs/ru/game/units/indicators.md`. «Есть» — правило уже в симуляторе и действует на новый
отряд без кода; «данные» — нужно только число из паспорта; «нет» — нужен код или замер.

## 2. Что нового (нет ни у одного из 17 наших отрядов)

1. **Дуга огня 360° со стрельбой на ходу** (звёзды): база `battle_entities.fire_arc_close` 360 у сущности
   `wh2_main_skv_infantry_fast_360`; наш максимум был ±35° (ополчение). В симуляторе стоя работает из паспорта, на ходу
   действует подгонка ±90° (`missile.move_fire_arc_deg`, по ополчению: «уходя, не стреляет»). Для звёзд это может быть
   неверно: в игре их суть — бить, отбегая. В сообществе числа нет (fandom / honga: «Fire Whilst Moving», без дуги; моды
   «360° fire arc» описывают, что с такой дугой отряд на ходу стреляет во все стороны без разворота). → замер M3.
2. **Настильный бронебойный огонь на 145 м** (аркебузы): правила есть, но всё замерено на пистолях 90 м, и у них уже
   открыто падение попаданий с дальностью. → замер M1.
3. **Перезарядка 13 с и 7 с** (новые базы в категориях `arrow` и `musket`). → замеры M1–M3.
4. **Вход сети «дуга огня»** — новый признак паспорта.

Всё остальное у рабочего набора — уже моделируемые правила с новыми числами.

## 3. Отложенные (одной строкой на каждый)

- Бегущие по канавам (оба): Stalk — скрыт на ходу везде, раскрывается ~170 м (fandom «Stalk»; в нашей пробе видимости
  охотники со Stalk видны с 80 м, `docs/ru/game/units/visibility.md`; база `unspottable_unit_reveal_distance` 20 м — для
  «неуловимых»); в симуляторе видимости нет (`vis` всегда истина). Ещё Snare-Net — аура на врагов (у нас ауры только на своих).
- Пистолетчики (конница): нет конницы в симуляторе, паспорт строит конницу неверно (берёт всадника вместо лошади).
