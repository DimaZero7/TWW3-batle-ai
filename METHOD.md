# Методика: как учим сеть

Сеть любого уровня не изобретает, а выбирает навык из выученных; навык — приём со словом, выученный одним учением по
рецепту ниже. Учим с нуля, снизу вверх, этапами по типам отрядов (`COURSE.md`).

## Уровень
Каждый такт: «оставить» или навык из открытых + указатель на короткий список кода (у тактика — клетка своей зоны).
Вход — то, что видит игрок, и свой приказ в силе с возрастом. Строки читает один «Анализ отряда»: выучен один раз на
фактах всех типов отрядов и заморожен для всех. Код только переводит указатель в координаты и ничего не решает; приказ
игре переотдаётся, только если точка ушла дальше порога из пробы. В учёбе, на экзамене и в игре — те же сети и код.
Гигиена — запрет, если: это механика игры с источником; он только убирает или задерживает приказ; мера с ним не хуже.

| Уровень | Такт | Навыки этапа 0 | Указатель |
|---|---|---|---|
| Стратег | до боя | по центру (= «оставить»), на гребне | гребень 1–3 |
| Оперативник | 15 с | Держать, Атаковать, Резерв, Обойти | рубеж, группа врага, сторона |
| Тактик | 5 с | отряду: держать, встречный удар, атаковать, отход | рамка, главная цель |
| Отряд | 1 с | исполняет: оставить / подправить в пределах приказа | место и курс в рамке |

## Рецепт навыка — один для всех
1. **Слова:** ситуация → глупый ход → нужный ход; две меры — исполнения (награда) и пользы (судья: бегство врага, удар
   в лоб, а не во фланг). Источник — бой человека, история или глупость ИИ игры (`game/manual.md`).
2. **Генератор** меняет всё, кроме причины; половина ситуаций — без причины.
3. **Экзамен до учёбы** сдаёт скрипт нужного хода: по мере пользы скрипт > «по умолчанию» > плохой скрипт; тут же
   замер «до» в общих боях этапа. Не сдал — чинить учение, не учить. Пороги — из этого замера (скрипт тем же путём),
   не догадки: шум — разброс меры по зёрнам, «лучше» — разница больше двух ошибок.
4. **Учёба.** Исполнение — наградой = мера исполнения. Выбор — метками парной игры: из одного состояния (и из состояний
   самой сети) все варианты на одних условиях, лучший по мере пользы — метка, разница в шуме — «оставить», такты смены
   с весом; ответ генератора — только проверка меток, учителя нет. Смесь: прошлые + новое + доля общих боёв этапа.
   Противник: скрипты (`ai_game`, `nearest`, `hold_shoot`), прошлые снимки сети, сама сеть.
5. **Экзамен после учёбы** — тот же, сдаёт сеть на новых зёрнах: не хуже скрипта, лучше «по умолчанию»; перенос — мера
   пользы в общих боях выше «до» (сим и игра против ИИ на «Нормальной»); прежние не просели; приказов игре в минуту
   ≤ 1,5× человека (с долей «оставить» в метках — вся защита от суеты); 2–3 боя глазами (`python -m game.vision`).
6. **Строка в журнал** `net/drills.json` (строка = учение): слово · уровень · откуда · команда · коммит · до → после →
   перенос · сдано + веса нижних, на которых училось. Повтор с нуля: тот же коммит, веса нули, строки по порядку.

## Порядок
В этапе снизу вверх: отряд → тактик → оперативник → стратег; на уровне сначала исполнение, потом выбор; одно учение за
раз. Первое дело: бегун пачкой (скорость общих боёв), мера У2 и три скрипта (прямо в рамку лицом / стоять / курс
наугад) — экзамен скриптами, он же замер «до».
