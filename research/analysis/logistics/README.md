# Очереди у препятствия в игре

Модуль [logistics](../../../docs/ru/apps/logistics.md) против «только движок»:
один и тот же шаг сближения в обход препятствия, 13–16 отрядов, `formation-probe`
на The Moorlands Route, скорость x20 (27.09.2026).

```bash
.venv/Scripts/python -m tools.build formation-probe --army gap_march_wide
```

```bash
.venv/Scripts/python -m tools.build formation-probe --army gap_march_wide --engine-only
```

```bash
.venv/Scripts/python -m tools.sim.logistics gap_march_wide
```

```bash
.venv/Scripts/python -m tools.analysis.logistics_game build/formation-probe/runs/<время> build/formation-probe/runs/<время>
```

## Итог по шагу в обход

Давка — сколько бойцов на пике стоят ближе 1 м к бойцам другого отряда; в
скобках — доля армии.

| Местность | Отрядов | Время: логистика / движок | Давка на пике: логистика / движок |
|---|---|---|---|
| скала (`rock_march_wide`) | 16 | 239 с / 208 с | **193 (13%)** / 538 (35%) |
| скала у края карты, одна сторона закрыта (`edge_march_wide`) | 16 | 157 с / 129 с | **30 (2%)** / 150 (10%) |
| проход 72 м между двумя скалами (`gap_march_wide`) | 16 | 165 с / 139 с | **42 (3%)** / 303 (20%) |
| только копейщики в два ряда (`spear_march_wide`) | 13 | 217 с / 213 с | **245 (17%)** / 650 (45%) |
| скавены: кланкрысы 160 и рабы 180 бойцов (`skaven_march_wide`) | 13 | 255 с / 215 с | **335 (16%)** / 516 (25%) |

- Модуль окупается там, где движок сминает много армии (скала, копейщики,
  скавены: четверть–половина на пике) — отряды не входят друг в друга, что
  вкусно для вражеской артиллерии и магии. Где движок сминает мало (край карты
  10%, проход 20%), полминуты сверху того не стоит: нужно правило «когда
  включать» (по угрозе и прогнозу давки).
- Эталон «движок» у края карты — первый прогон, где из-за ошибки (край карты
  принят за препятствие во весь марш) логистика отдала всем прямые приказы.
- Застревания (движется, но за 10 с меньше 2 м) — по 10 с в обоих вариантах:
  это отряд у своего места доводит строй. После правила «сужаться только по
  нужде» перестроек после прохода нет (раньше узкие отряды стояли по 10–16 с
  перед проходом и на месте).
- Доводка после обхода чистая (давка 0), после исправления обмена местами.

## Что нашли по пути

- Приказ с шириной меняет её только в точке назначения → сужение на месте до выхода.
- Край карты сбоку от фланга принимался за препятствие во весь марш → полоса
  ищется в полосах самих отрядов.
- План «ни одного касания» (всё в пространстве и времени) в симуляции на
  20–90 с дольше — выключен; касание движок разводит сам.
- Время скрипта за такт: чтение всех бойцов (для замера давки) ≈ 50 мс,
  решение сближения с маской всего поля 60–100 мс, план логистики 5–26 мс один
  раз. На x20 такт — 50 мс реального времени, отсюда рывки (задача на будущее).
