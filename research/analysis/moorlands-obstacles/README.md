# Moorlands Route: анализ препятствий

Какие препятствия на карте [The Moorlands Route](../../../docs/ru/game/maps/moorlands-route.md)
видит `is_area_clear`. Без запуска игры, по уже снятой сетке 3 м (`research/evidence/maps/moorlands-route/capture-20260926`,
локальный архив).

Повторить:

```bash
.venv/Scripts/python -m tools.analysis.obstacles research/evidence/maps/moorlands-route/capture-20260926 research/analysis/moorlands-obstacles
```

Файлы: `summary.json` (всё ниже в цифрах), `gaps.csv`, `obstacles.png`, `clearance.png`.

## Выводы (27.09.2026)

1. **Препятствий по `is_area_clear` всего 10 групп**, все крупные (42–114 м,
   58–481 клеток): скалы, утёсы, руины. Одиночных мелких препятствий нет.
   4 группы прижаты к краю рамки радара.
2. **Узких проходов между скальными группами нет**: ближайшие группы разделены
   72 м, дальше 83, 84, 135 м. Строй шириной до 40 м проходит между ними свободно.
3. **Есть вогнутые формы — «углы»**: группа 7 (264; 35) — Г-образная,
   группа 9 (216; 180) — подкова, группа 4 (−221; −103) — полумесяц; вогнутость 0,32–0,37.
4. **Крутые склоны совпадают со скалами**: из 279 клеток круче 35° свободной
   значится только одна.
5. **Заборы `is_area_clear` почти не видит**: 292 секции (≈5,8 м), 29 линий
   по 24–58 м; рядом с препятствиями только 5 секций из 291. Щебень всегда
   внутри скальных групп.
6. **Просветы между линиями заборов — 3,6–4,2 м** свободного места (оценка:
   расстояние между центрами секций минус длина секции): около (12,7; −32,4),
   (321,6; −4,3), (−168,8; −50,3), (31,7; −6,2)… Это настоящие узкие проходы —
   **если заборы мешают движению**.

## Пробелы в данных

| Пробел | Почему важно |
|---|---|
| Достижимость по клеткам не сохранена (при снятии считалась только сумма, для диагностического отряда) | Проверить, что `is_area_clear == false` действительно «нельзя встать/пройти» |
| Мешают ли заборы движению | Решает, есть ли на карте узкие проходы |
| Сетка 3 м грубая для просветов 4 м | Нужна сетка 1 м в окнах вокруг тестовых мест |
| Размеры строя и поведение движка у углов и в просветах | Сколько места нужно строю у препятствия; частично закрыто [хутором](../hamlet/README.md) |
