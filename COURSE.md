# Курс сети

**Цель.** ИИ для боёв TWW3 без глупостей стокового ИИ, не чемпион. Итог — мод; архитектура открыта сообществу:
люди предлагают приёмы, мы делаем из них учения.

**Главная идея: армейская доктрина.** Бойцов, роты и штабы учат приёмам на учениях, а дальше военная машина работает
сама. Написать алгоритм боя целиком трудно — трудно именно многообразие; сделать одно учение легко. Каждое учение даёт
навык — приём, который человек назовёт словом: скрипт учения показывает нужный ход, сеть его перенимает. В бою
войсками командует сеть: выбирает, какой из выученных навыков применить сейчас, кому и где, сочетает их и может
вывести своё; навык по умолчанию — держать позицию. Так сеть не кот в мешке: обучение управляемо и прицельно — есть
глупость, делаем учение. Гигиена исполнения (не суетиться, не бросать живую цель) действует всегда и не выбирается.

| Уровень | Выбирает | Примеры навыков |
|---|---|---|
| Стратег (раз до боя, вслепую) | шаблон расстановки | линия на высоте, снайперы глубоко за пехотой, фланг в лес, косой строй |
| Оперативник (15 с, до 40 групп) | навык каждой группе | держать, связать и обойти, резерв в прорыв, встретить быстрых, Канны |
| Тактик (5 с) | строй и способ боя группы | фаланга без дыр, упор, встречный удар, огонь через голову, фокус до бегства |
| Отряд (1 с) | ничего — исполняет | без сети: скрипт + рефлексы |

Такт решения — взгляд на новые данные, не повод менять план: по умолчанию «оставить», уровень помнит свои приказы.

**Почему так.** Линия S (одна сеть, учёба на исходе) — чёрный ящик, нужна гора боёв, глупость не починить. Линия
генерала g1–g48 — приказы не влияли (−0,24 у генерала, учителя и случайных), потолок — ремесло исполнителя.

**Как учим.**
1. Учение = одна тонкость или глупость: ситуация → глупый ход → нужный ход → мера.
2. Источники: бои человека (лес, фланг, снайперы глубже), история (фаланга, косой строй, Канны, резерв, Азенкур),
   глупости ИИ игры.
3. По одному учению, и часть — в общих боях этапа, для обобщения. Самое сложное — разнообразие: генератор меняет
   условия так, чтобы сеть обобщила причину, а не запомнила место; проверяем на условиях, которых в учёбе не было.
   До обучения — экзамен скрипту учения и замер «до». Смесь = прошлые учения + новое + доля общих боёв этапа. Перенос
   в общем бою после каждого учения; нет переноса — ищем причину.
4. Этапы по типам: 0 пехота → 1 + навесные → 2 + снайперы и орудия → 3 + быстрые → 4 + монстры и лорд → 5 матчапы.
5. Методы: подражание скрипту учения; парная игра в симуляторе и подражание лучшей ветке; обучение на результат —
   малой добавкой в конце.
6. Скрипт учения — учитель одного приёма, а не алгоритм боя: общего учителя-формулы на весь уровень нет.
7. Опора на реальность: симулятор строго по игре, вход сети один в один, судим по боям в игре и кадрам боя.

**Чего не делаем:** писать один алгоритм на весь бой; подбирать правила под победу; учить на исходе боя; начинать с
полных матчапов; верить числу, не посмотрев на бой.
