# TWW3 battle AI

## Безопасность
- Бои против ИИ игры — только «Нормальная»; игра — только на RTX.
- Нигде `rm -rf`, `git reset --hard`, `git clean`.
- Никаких кликов и нажатий на рабочий стол, пока пользователь за компьютером.
- Есть `state/HUMAN_PLAYING` — игру не запускать и не трогать (лаунчер откажет сам: `ops/guard.*`).

## Карта
- [sim/](sim/README.md) — симулятор боя на PyTorch; числа только из игры.
- [bridge/](bridge/README.md) — мост Lua, сборка пака, лаунчер, помощник в Docker.
- [net/](net/README.md) — сети уровней (отряд → тактик → оперативник → стратег), обучение, веса.
- [game/](game/README.md) — бои в игре, пробы механик, разметка человеком.
- [reverse/](reverse/README.md) — разбор программы игры (Ghidra), места памяти для memreader.
- [contract/](contract/README.md) — договор на стыках и тесты паритета (вход сети один в один).
- [ops/](ops/README.md) — Docker, замок игры, что висит; `design/` — страницы пользователя (тактик, отряд).
