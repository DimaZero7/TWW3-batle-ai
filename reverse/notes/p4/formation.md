## Главное
Отряд, стоящий без поведения (стек поведений отряда +0x3310 = 0 — так у всех отрядов пробы), держит **подприказ группы
«стоять»** (вирт. 143ae4858, тик 143287b5c, машина +0x30, ставит её сама группа 1430e5b34 → 14326a4f8). Прошлый разбор
(mechanic.md 6.3, класс 14390f070) смотрел не туда: тот класс — поведение «стойка» (FORM_DEFENSIVE_STANCE и т. п.) при
приказанной стойке; порог 1,25/0,75 там, не здесь.

Состояния подприказа (В, таблицы имён по слоту +0x20 вирт. состояния):

Тик 143287b5c **каждый такт ищет врага**: 142f5d3ec(юнит, R) — все отряды вражеского союза, у кого 142f49344: расстояние от
прямоугольника группы (+0xb68) меньше R + размер; R = 35 м, 40 м если враг уже был (+0x60 != 0). Ближайший — в +0x60
(142d79764: квадрат расстояния край-край прямоугольников). Фильтра по бегству/видимости нет (С).

IDLE → READY: 14328430c: 14303425c(юнит) (не в рукопашной +0x154 == 0 и т. п.), и (+0x60 != 0 или свои цели залпа).
READY держится, пока условие верно: **в READY нет проверки перестроения**, поэтому строй не смыкается до конца.

IDLE → REFORM: 143283398: нет атрибута 0x53; 14304d01c(+0x270) (место отряда готово, бойцов не больше мест); стек поведений
пуст или верх +0x1e0; 14301d888 (не в бою и т. п.); +0xcec группы == 0. Дальше: если +0x6c == 0 → да (первый раз); иначе, если
143033998 == 0 и +0x154 == 0 и **сейчас > +0x6c + 5 с**:
- мера «на месте» не свежа (1430da6b4: среднее ≥ порог при последнем замере) → да;
- или бойцов > 4 и **в IDLE дольше 10 с** (+0x68 > 100) и есть боец дальше 0,2 r от места (+0xd0c4 != 0) → да.

REFORM: подприказ «по местам» получает флаг перестроить = 143279838 (+0xd0c0 и +0xd0bc == 0). С флагом — места заново на
нынешнее число бойцов при той же ширине; без него — только «вернуться на свои». Конец подприказа (1432882e0): +0xd0c4 = 0,
+0xd0b8 = такт. Смерть: +0xd0c0 = 1; +0xd0bc = 20 (2 с), если умерший уже вне строя (бит 0x10 +0x108 снят: летит, лежит).
