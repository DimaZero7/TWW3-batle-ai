## 2. Дальность обнаружения прячущегося (`14301d9e4`) — В
```
только в фазе боя (режим 6..9), наблюдатель не бежит (1430348f0), у обоих есть бойцы
если цель прячется и у неё unspottable (0x17): D = 20 м (kv +0x4178)
иначе:
  D = stat(наблюдателя, 0x1c spotting_forest если самая частая земля под целью = лес, иначе 0x1d spotting_scrub)
      × scalar_visibility_sight_modifier наблюдателя (0x44)
  D += 20, если цель ещё НЕ «по-настоящему скрыта» (+0x3d34 = 0) — то есть пока идут её 5 с
  D = D × 0,8 ночью × множитель погоды (142dcc810)
  D = D × hiding_scalar цели × (ночь: 0,75 атакующему / 1,0 защитнику)
обнаружен, если расстояние между прямоугольниками строя < D (142d6a204)
```
Наши: spot_dist_tree 60, spot_dist_scrub 80 (джезейлы 160/160); hiding_scalar 0,8 кланкрысы/рабы/бегущие,
0,9 ночные бегуны, 1,0 остальные. Кланкрысы в лесу: 60 × 0,8 = 48 м.

## 3. Кто «в лесу» (`143022250`) — В
- Счёт по бойцам: у каждого бойца своя клетка земли (+0x240, сетка 2 м). hide_forest засчитывает бойца, только если
  его клетка — тип 0 «лес» (не 15 «редкий лес»); stalk — любого бойца.
- Порог доли: > 85 % — начать прятаться, > 75 % — остаться (`new_units_module.md` §1.2).
- «Самая частая земля» отряда (+0x3d24) — тип, на котором больше всего бойцов; от неё зависит, какая зоркость
  (лесная 60 или открытая 80) работает против этого отряда.

## 4. Видимость обычных (не спрятанных) отрядов — В (ход), С/Н (числа)
```
142de2830 (сторона, каждый тик):
  если тумана войны нет (флаг +0x118 = 0) или особый режим → 142dd8c64: все вражеские отряды в список «видимые»
  иначе только 142daffe8: для каждого врага (на поле, есть бойцы):
       виден без проверки, если особое состояние (142db0f5c: огонь по готовности (С), бегство (С), revealed …)
       иначе, если хоть один наш отряд «видит» его: расстояние край–край < R × hiding_scalar цели (142ddb630),
             R = запись наблюдателя +0x190 × scalar_visibility_sight_modifier × множитель земли (стат 0x1e)
                 × (ночь 0,8) × погода (14304d06c)
  итог: видимые = из списка, у кого нет «по-настоящему скрыт» (+0x3d34)
```
- **Проверки линии взгляда по рельефу (холмы) в этом коде нет** — только расстояние край–край. В.
- Что за поле +0x190 (visibility_spotting_range_min 40 или _max 1500) — по раскладке записи не установил (Н);
  проба 25.10 видела не спрятанные отряды на 484 м → на практике дальность ≥ 484 м (по смыслу 1500).
- Интерфейс «наблюдателя» `14302b494` (высота глаз = верх самого высокого бойца, таблицы по размеру) существует,
  но его вызов не найден; по смыслу — отрисовка тумана войны (строки `fog_of_war_heights`, шейдеры) — Н.

## 5. Что видят игрок и ИИ про скрытый отряд — С
- Список видимых +0xf0 скрытый отряд не содержит → Lua `is_visible_to_alliance` = нет; интерфейс скрывает отряд.
- ИИ игры: задачи против бойцов скрытого отменяются; ИИ помнит прямоугольник строя в момент потери из вида
  (`14318ca40`, `new_units_module.md` §1.5).
- Своя сторона видит свой спрятанный отряд (значок IsHidden = +0x3d34).

## 6. Раскрытие и повторное прятание — из `new_units_module.md` §1.2–1.3 (В/С)
Раскрывает: обнаружение по дальности (§2), рукопашная любого бойца, огонь по готовности, стрельба на ходу,
способность (кроме snipe), движение в рукопашную, простое движение — только если нет stalk И отряд не в лесу;
приказ атаки (С; проба 25.10: не раскрыл). Бег stalk/hide_forest в лесу не раскрывает.
Время: 5 с непрерывно до «по-настоящему скрыт»; потерял условия — ещё 1,5 с скрыт; обнаружен — раскрыт со
следующего тика; был раскрыт < 1,5 с — снова скрыт сразу, дольше — снова 5 с.
