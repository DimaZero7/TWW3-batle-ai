Дата: 24.10.2026. Только файл игры на диске, открытый код. Игра не запускалась, отладчика и дампов нет. Свой проект

Уверенность: В — код прочитан целиком; С — код прочитан, смысл поля по контексту; Н — догадка.

## 0. Главное

**В игре нет правила «сколько бьют одного» для пехоты. Удар начинает только боец, чьё тело касается врага, а свои
тела не пропускают: боец второго отряда, упёршийся в своих, через 0,3–0,5 с останавливается и не идёт в обход.**
Поэтому число бьющих по отряду врага задаёт длина его стороны, к которой могут прижаться тела, а не число отрядов
сзади. Второй отряд в первом добавляет только тех, кто нашёл свободное место у врага (края, угол) — отсюда 0,99 и 1,08.

Отряд, получив приказ атаковать, раздаёт цели только **первому ряду** (числу колонн строя); остальные идут на свои
места в строю. Никаких множителей урона или попадания за перевес нет (`melee_outnumbered_defence_penalty` = 1).

## 2. Правила

### 2.1 Отряд раздаёт цели только первому ряду (`14327c350`, `143065020`) — В (код), С (порядок бойцов)

```
колонн = min(бойцов, int((ширина + 0,001 − a) / s) + 1)      # a, s — поля формы строя (+0x10, +0x18)
для i-го бойца в списке отряда (i = 0, 1, …):
  если i < колонн:  цель = ближайший боец отряда-цели в «дорожке» бойца
  иначе:            цели нет, боец идёт на точку (своё место / точку в области атаки)
```
- «Дорожка» (`143277508`): враг подходит, если его боковое отклонение от линии «боец → направление атаки отряда»
  меньше w + радиус врага; w = min(10 м, 1,6 × радиус бойца × поле записи +0x64), пробуется w × 1, 2, 4, 8.
- **Предела занятости у пехоты нет** (параметр предела = −1). Предел есть только у летающих по нелетающей цели:
  цель берётся, если её уже бьют не больше 1 (то есть всего ≤ 2); при перераздаче после сдвига врага — не больше 4
  (`143288918`, параметр 4). Для пехоты обе ветки выключены (условие — «летающий» отряд, `143014c58`).
- Слоты строя идут по списку бойцов (`143286cd0`: место i — боец i), поэтому первые «колонн» бойцов — первый ряд (С).
- Точка атаки отряда: середина ближайшей стороны многоугольника строя врага, ширина = min(своя, длина стороны) × 1,15
  (`14327c350`, `FUN_14182dc14`). Свой отряд, уже стоящий там, не учитывается (проверка места — по карте, С):
  **правила «встать с другой стороны» нет** — второй отряд идёт к той же ближайшей стороне.

### 2.2 Начало удара — только при касании тел (`14308f0e0`, `14305e8e0`) — В

Боец в подходе по приказу отряда начинает удар по своей цели, если:
```
расстояние центров < r_бойца + r_цели + 3 с × |v_цели − v_бойца|     (не больше 1000 м)
и цель в пределах ±15° от его взгляда (cos² = 0,933)
```
- r — радиус тела из базы (`battle_entities.radius`, у всей нашей пехоты 0,65 м). Стоят оба — **1,3 м между
  центрами, то есть тела касаются**. Сближение 3 м/с добавляет 9 м (начало удара на подбеге).
- Скорость берётся из полей бойца +0xe0/+0xe8 (вектор скорости: так же используется в `14308b938`), С.
- В свободном бою (`14308b938`, действие «бить этого бойца»): удар начинается при зазоре < 3 × масштаб, масштаб =
  радиус записи × 1,667 (+0xae0, `143052ba8`; у пехоты 1,08 м → зазор 3,25 м), но только если на линии к цели **нет
  врага**. Свои линию не закрывают, но попадание всё равно решает размах оружия (раздел 2.5).

### 2.3 Свои тела: упёрся — встал (`14308f0e0`, `14308ab10`, `143083f7c`) — В (ход), С (смысл флагов)

- В подходе боец каждый тик смотрит в конус ±30° (cos 0,866) на 8 м вперёд (`14305e8b4`: у малых 8 м, у больших
  8 × масштаб, не больше 40) и кто стоит в его дорожке на 30 м вперёд:
  - **свой в дорожке ближе 1,5 × (r + r) ≈ 1,95 м** — флаг «свой впереди» (считается, когда отряд вступил в бой и
    боец идёт вперёд быстрее половины своей скорости);
  - при своём впереди врага из дорожки он берёт целью, только если враг ближе этого своего; иначе цели нет.
- Отряд «вступил в бой» — флаг у каждого бойца свой: маска 0x04 байта +0xe4 его действия подхода; взведён — в этом
  действии больше не пересчитывается (`143087d24`: 143087d31, 143087d69, 143087e5b–143087e6a). Условие: N ≥
  ceil(0,3 × max(1, min(своих, чужих) / рядов)) — 30 % фронта; «чужих» берётся, только если у бойца есть боец-цель
  (+0x38, 143087db8–143087ddb), иначе в формуле одни «свои»; рядов 0 → 3 (143087d9e–143087da2).
  N — не пары, а сколько **разных бойцов отряда-цели** было в касании с любым бойцом своего строя, каждый один раз
  (`1430cb814`: 1430cb99d–1430cb9a6, 1430cba24), из списка, закрытого на прошлом тике строя (`1430d8e08` ←
  `1430e5b34`; читает `1430da12c`: +0x14 / +0x18 списка строй +0xcf0). Касание для этого списка — центры не дальше
  max(r + 1 м, a) + max(r + 1 м, b) (1430cb8e2–1430cb941; a, b — число из записи отряда +0x50 → +0x140 → +0x2c, не
  разобрано): от 3,3 м при r = 0,65, шире касания тел 1,3 м. (В; исправлено 14.11: было «пар касания»)
- Во вступившем отряде боец **останавливается** (`14308ab10`):
  - скорость ниже 30 % своей дольше 0,3 с (2,0 с, если у него есть свой счётчик атак, `14306dbac`), или
  - «свой впереди» дольше 0,5 с (при флаге приказа +0xc4 бит 2), или
  - вышло время подхода: расстояние / скорость + 2 с (+0xd4, `1430538b4`).
  Если он уже замахивается — просто стоит (+0xe4 |= 0x20), иначе подход закончен; дальше он стоит на месте или
  возвращается на место в строю, когда отряд пересчитывает строй (`143286cd0`: больше 1,5 м от места + запас).
- **Обхода нет:** в коде подхода нет шага в сторону от своих. Шаг в сторону (на 0,5 × масштаб) есть только в
  свободном бою и только от **врага** на линии к цели (`14308b938`, до 3 врагов; больше 3 — стоит).
- Своё место занято своим (`143083f7c`: стоящее тело своего на точке движения ближе r + r) → боец считает, что
  пришёл (+0x1b0 = 1, событие касания `14306bc78`). Внутрь чужого своего отряда он не втискивается.
- Обгон в движении (`142f6c310`): из двух движущихся пропускает более медленный, если другой быстрее в 1,1 раза
  (1,4 раза — в одной группе). Стоящий не уступает (код 9).
- Касание тел включено и со своими, и с врагами (маска +0x6c: бит 0 свои, бит 1 чужие); выключается только у сбитых:
  `collision_disable_delay_knocked_back_vs_friends` 2 с, `…down_vs_friends` 0 с, `…flying_vs_friends` 0 с.
- Расстояние касания — сумма радиусов (1,3 м у пехоты). Сам расчёт расталкивания (насколько тела входят друг в
  друга до толчка) **не найден** (раздел 4); 1 м из наблюдений не противоречит 1,3 м с мягким расталкиванием.

### 2.4 Кого бьёт тот, у кого нет цели или цель занята — В

- **Касание врага = удар по нему** (`14306bc78` → `143056730`): боец без своего боя (подход, строй) сразу получает
  приказ бить коснувшегося врага. Если он уже бьёт другого, переключается, только если коснувшийся стоит на линии к
  его цели.
- Цель погибла → новая из отряда-цели раз в 8 тиков (тик ^ номер бойца & 7 = 0):
  `очки = расстояние + 10 м × (сколько уже бьют кандидата)`, берётся наименьшее (`14302e7d8`). То есть боец
  предпочтёт свободного врага, даже если он дальше на 10 м за каждого занятого. Это **мягкое** правило, не предел.
- В свободном бою цель пересматривается раз в 3 тика среди 16 ближайших в 3 × масштаб (3,25 м) — `melee_module` 2.4;
  счётчика занятости там нет.
- Враг, задетый размахом, получает приказ бить того, кто его задел (`143080ca0` → `143074dcc`, если тот досягаем).

### 2.5 Свои на размахе оружия — В
- Свой из **другого** отряда, задетый размахом, урона не получает и **не расходует** число задеваемых (N = 1 у пехоты):
  удар достаётся первому врагу дальше по размаху (`143080ca0`: счётчик уменьшается только на враге). Бойцы своего
  отряда в размах не попадают вовсе. То есть свой не закрывает врага от удара — закрывает только тем, что бьющий не
  может подойти: длина размаха задаётся анимацией (в коде её нет), а со второго ряда при зазоре 1,3 м + тело своего
  до врага ~2,6 м между центрами типичный размах не достаёт (С).

### 2.6 Темп и урон при тесноте — В
- Отдельного «давка режет урон» нет: шанс и урон не зависят от числа бьющих (`142e58560`; `melee_outnumbered_defence_
  penalty` = 1,0 — ветка есть, множитель единичный). Темп — таймер от начала замаха (`melee_module` 2.6).
- Теснота работает только через движение: заблокированный не начинает удар (2.2) или машет, не доставая (2.5).
- Направление удара (фланг/тыл: защита × 0,6 / × 0,3) считается для каждого бьющего отдельно — не от числа отрядов.
- `melee_secondary_attack_probability` (1,0) — вторые удары внутри парной схватки (`melee_module` 2.7), не «второй
  атакующий на одного».

## 3. Сравнение с нашим симулятором (только чтение `tools/nn/sim/melee.py`, `battle.py`, `config/nn/sim.json`)

Как у нас: бьющие F = 0,5 × длина стороны касания / шаг строя (на пару отрядов), потом пределы: по сторонам
бьющего; `target_face_cap` (вкл.) — отряды, бьющие цель через одну её сторону, делят длину этой стороны; общий предел
своих бойцов; затем «волна» начала боя `wave` (× (1 + 1,48 e^(−t/10,25)), t — младший из часов пары).

| пункт | игра (код) | симулятор | итог |
|---|---|---|---|
| кто бьёт | тело касается тела врага (r + r = 1,3 м стоя, ±15°) | отряды касаются коробками (reach −2,5 м) — бьют все пары | основа одна, единица разная: у игры боец, у нас отряд |
| свой впереди | упёрся 0,3–0,5 с — встал, не обходит | своих отрядов не расталкиваем (`friend_push` false), стоящий в своём бьёт как свободный | **расхождение** |
| сторона цели | куда тело реально дошло | по пеленгу центра бьющего (`rel_j`) | второй отряд со сдвигом центра на 2–8 м попадает на другую сторону цели (фланг) и не делит длину с первым — **вероятный источник 1,32** |
| обхват с фланга | только если тела дошли до фланга (обхода своих нет) | `flank_face striker`: через фланг бьющий приносит весь свой фронт («обходят») | для наложенного отряда в игре нет; `flank_face_busy` режет только «новичка», пришедшего позже, и только через фланг |
| волна начала боя | новых тел в касании нет — нет и волны | волна × до 2,48 на паре с младшими часами **после** `target_face_cap` | **расхождение**: свежий наложенный отряд получает полную волну сверх предела стороны — вероятный источник 1,81 у трёх |
| предел на одного врага | нет (у пехоты) | `melee.pairs` 2 только в лаборатории бойцов (выкл.) | в коде игры у пехоты такого предела нет; правило «≤ 2» есть только у летающих. Включать `pairs` как правило игры нельзя; сходный итог даёт геометрия касания |
| только первый ряд | цели получает первый ряд (колонн), остальные стоят в строю | `fighting_files` 0,5 от фронта, `front_fill_ranks` | совпадает по смыслу (замерено) |
| перевес | множителя нет (1,0) | нет | совпадает |

**Что поменять, чтобы стало как в игре (предложение, не правка):**
1. Предел стороны цели считать по месту, а не по отряду: суммарные бьющие через сторону j ≤ 0,5 × длина стороны / шаг
   (как сейчас), но наложенный отряд (его коробка перекрыта своим, который касается той же цели) относить к той же
   стороне, что и свой впереди, и давать ему только непокрытую своим часть фронта (края).
2. Применять `target_face_cap` **после** волны (или считать волну только для новых тел в касании): свежий отряд за
   спиной своего не даёт волны.
3. `flank_face striker` не давать отряду, чей путь к флангу цели закрыт своим (он не обходит).
Ожидание по коду: два наложенных ≈ 1,0 одного, три ≈ 1,0–1,1 (добавка только с краёв), как в замере 0,99 / 1,08.

## 4. Не найдено

  +0x120/+0x124, не найден (тот же пробел, что в `charge_module` 6).

  самой раскладки (`143ad5588`) не читал — С.
- Проверка места атаки `1431017cc` (карта или ещё и свои отряды) — С: по виду это проверка проходимости.
- Поля записи бойца +0x64 (множитель ширины дорожки) и +0x98 (`combat_reaction_radius`, у пехоты 0 — авто-удар по
  радиусу выключен) — по совпадению с базой, С.
