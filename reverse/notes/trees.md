## 2. Тела деревьев — В
```
142db918c: для каждой модели из списка деревьев карты (имя модели; можно с суффиксом после '|'):
  запись = tree_metadata[модель]; нет записи → тел нет
  R = запись.CollRadius (0 → 0,85);  H = запись.CollHeight
  для каждого экземпляра (x, z, масштаб s), если круг R (без масштаба) внутри рамки поля боя (бой +0xc0..+0xcc):
     тело(радиус = min(s·R, 2,25), высота = s·H) в (x, z)
142f3197c: масса 500 (оба параметра 0x43fa0000); высота < 0,3 → снять бит 0 флагов +0x68 (Н: не задерживает)
```
- Тело — вертикальный цилиндр от земли на всю высоту дерева. Кроны отдельно нет.
- Модели без строки в `tree_metadata.txt` тел не получают (на Кислеве — wh_oak_tree_l/m, 9 штук).

## 3. Снаряд и дерево — В (ход), С (геометрия теста)
```
1430bb044 (каждый шаг снаряда): отрезок пути → опрос 142db3470 с маской 0xeb0d
  попалась запись категории 8 без бойца (слот 0x38 = 0), слот 0x98 = 0, слот 0x70 = дерево:
     пропуск = (время полёта снаряда +0x11c ≤ projectiles.vegetation_ignore_time, запись снаряда +0x108)
     ... если не пропуск: отметить попадание, снаряд состояние 7 (остановлен, урона нет); у артиллерии
         (категория 0) ещё 142f3a358: один раз на дерево, 5 % — 142f85afc (Н)
```
- `vegetation_ignore_time` в базе подобран как **≈ 42 м / начальную скорость** у всех классов (медиана расстояния
  42 м в каждой категории): лук 45 м/с — 0,93 с, пуля 100 м/с — 0,42 с, праща 50 м/с — 0,84 с. 0 у 250 артиллерийских,
  77 стрел (башни) и др. — те ловятся деревьями с вылета.
- Атрибутов отряда в этой ветке нет: «стрельбы сквозь деревья» у лесных эльфов в коде нет; у их стрел то же 42 м.
- Тест: тот же опрос тел, что для бойцов (цилиндр, `14315e8a4`), радиус снаряда `collision_radius` (стрелы 0,1,
  пули 0,05) — С.
- Проверка линии огня (маски 0x4801/0x4809) деревья не смотрит: из тел учитываются только бойцы (`142f55074`,
  `1430c0dd0`) — С (согласуется с `volley_module.md`).

## 4. Бойцы и деревья — В (столкновение), С/Н (последствия)
- Дерево и боец — пара в общей физике тел (`143170100`); у бойца со strider или ignore_trees пара отключена.
- Последствия: толчок по массам (боец 100, дерево 500), реакция бойца по уровню толчка (`charge_module.md` 5.4,
  `143059bc8`; сам расчёт толчка не найден). Особого правила «натиск прерывается о дерево» нет (Н).
- Место в строю внутри ствола: стоящий строй возвращает бойца на место, только если он дальше r + 1,5 м
  (`melee_turn.md`, `143286cd0`) — боец, оттеснённый стволом на ≤ 1 м, считается «на месте» (С).

## 5. Где лежат деревья — В
- Список экземпляров — файл карты `*.tree_list.bin` в пакете плиток (Кислев: `ksl.tree_list.bin` в `tile074.pack`;
  разбор формата и привязка — `TWW3-batle-ai/docs/ru/game/map/vegetation.md`, архив research/evidence/map/forest-trees-20260925).
  Строки `.tree_list.bin`, `default.tree_list`, `tree_list_reference_file` в программе.
- Радиусы/высоты — `vegetation.pack: battleterrain\vegetation\trees\tree_metadata.txt` (59 739 байт).
- Кислев (рамка ±512 м): 5168 точек, 5159 с телами, 3724 в лесу (лес 129 420 м²). Радиус тела: медиана 0,40 м
  (p10 0,26, p90 0,50, макс 1,10); высота: медиана 14 м, ниже 2 м — 10 %. Плотность 0,029 /м² (одно дерево на 35 м²,
  шаг ~5,9 м); стволы занимают 1,6 % площади леса; клеток 3 м со стволом 26 %.
- Перехват (простая оценка, деревья выше 2 м, путь ниже крон): λ = Σ 2(r + r_снар) / площадь = 0,023 /м (пуля) —
  в среднем один ствол на ~44 м пути; P за 10 / 20 / 40 м: 0,20 / 0,37 / 0,60.
- Бойцы: стволов на пути шага (r + 0,5 м) — один на ~19 м; доля мест строя (шаг 1 м) внутри ствола + 0,4 м — 5,9 %.
