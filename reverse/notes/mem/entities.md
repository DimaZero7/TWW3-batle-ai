# Бойцы отряда в памяти игры (01.11.2026, для memreader-проб)

Warhammer3.exe 15.10.2026 (sha256 9bd58c63…e496). Статический разбор + проверка в игре (memreader 0.15.1, 3 боя пробы
`cavcharge`). Места и смещения — в `build/mem/sites.json` проекта (вне git); здесь — откуда они.

## Путь
- Скриптовый отряд → боевой отряд: `[obj + 0x8]` (перехват `ammo_left`, как у снарядов). Сборка отряда: вызвать
  `unit:ammo_left()` — префикс видит объект; после привязки перехват снимается.
- Боевой отряд `+0x180` — вектор бойцов {cap u32 +0x180, size u32 +0x184, data* +0x188} (указатели). Источник:
  `notes/fatigue/dec_b2.c` (`14301e194`), `dec_b3.c` (`1430472a8`: среднее усталости по `+0x188`/`+0x184`).
  **Погибшие из вектора уходят** (160 → 154 — ровно `number_of_men_alive`).
- Часы: отряд `+0x30` → бой, бой `+0x440` → мир, мир `+0x98` — такт (u32), «сейчас» = такт × 0,1 с
  (`14305ec7c`: `[[man+0x50]+0x440]+0x98 × [143d0e294]=100 × 0.001`).

## Как нашёл цель
Поиск в игре (`apps.mem.entities.discover`): у 12 бойцов отряда — смещения 0…0xc00 шагом 8, где лежит указатель на
бойца врага. У рыцарей стабильно `0x2c0` и `0x368` (12 из 12 на 3-й с), у пехоты `0x368` и `0x3d8`. 0x368 = задача
+0x330 + 0x38 (цель задачи `14308f0e0`). Проверка: удар рыцаря по цели +0x368 — на 1,9–3,3 м между центрами.

**Ошибка первой версии:** поиск шёл на два уровня (каждый найденный указатель разыменовывался ещё раз) — после ~10⁵
таких чтений состояние Lua в игре сломалось (числа стали функциями, бой упал на 18,5 с). Чтение только своих полей
бойца — без падений.

## Цена
660 бойцов (6 отрядов) за опрос: 3–12 мс процессора (медиана 5–7), опрос 0,1 с боя; такт за опрос не сдвигается
(в начале и в конце опроса — один такт).
