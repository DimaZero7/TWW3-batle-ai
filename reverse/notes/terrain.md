## 2. Рукопашная — В

```
1430a6880(атакующий a, защитник d):
  если размер a ≥ 4 или размер d ≥ 4 (very_large): Δh = 0
  если ни a, ни d не в натиске (142e52cc4):        Δh = y_d − y_a
  иначе:  r² = (x_d−x_a)² + (z_d−z_a)²;  Δh = (y_d − y_a) / r²   (если r² ≠ 0)   # без корня — так в коде
142e589a4:
  h = 0;  если max_diff (1,0) > 0:  h = coef (0,3) × Δh / max_diff
  h = clamp(h, −coef, +coef)
  если h > 0 и у отряда бьющего атрибут 0xd (strider): h = 0
  m_высоты = 1 − h          → умножает обычный и бронебойный урон (вместе с отражением и т. п.)
```
- Шанс попасть высоты не видит (`142e58560`: только атака/натиск/защита, слоты бойца). В.
- Кто именно «бьющий» в проверке strider — объект `rbx` = боец-интерфейс, слот 0 → отряд; по смыслу атакующий (С).
- Делитель r² вместо r в натиске: мера «уклон / расстояние». При касании r ≈ 1 м почти то же; при r = 2 м — Δh/4.

## 3. Снаряды — В

```
14309b804: Δh = y_точки_стрелка − y_цели (ноги бойца-цели +0x8c)
           точка стрелка = ноги живого бойца-стрелка (снаряд +0x20 → +0x88/+0x8c/+0x90), иначе точка снаряда +0xf4
142e5955c:
  m = 1
  если снаряд не помечен (байт +0x70 ≥ 0; смысл Н):
     если стрелок НЕ strider или Δh > 0:
        h = 0;  если melee_max_diff (1,0) > 0 [так в коде — проверяется рукопашный ключ]: h = 0,3 × Δh / 40
        m = 1 + clamp(h, −0,3, +0,3)
  обычный и бронебойный урон × m, потом округление
```
- 40 м вниз → ×1,3; 40 м вверх → ×0,7; линейно между. Strider-стрелок снизу штрафа не получает.
- Точность (`shooting_module.md` 2.1): p ∝ (1 − θ/180), θ — угол вылета; θ решает баллистика `1430a11c0`:
  дискриминант v⁴ − g²d² + 2·g·v²·Δy (g в записи снаряда отрицательная) — выше цель → больше θ → ниже точность; нет
  решения (D < 0) → выстрел невозможен. d — горизонтальная (X/Z).
- Дальность (`142d6a204`): прямоугольники строя, только X/Z. **Высота дальность не увеличивает** (вопреки «academy»).
- Линия огня (`volley_module.md` 3): 3 луча по настоящей траектории; земля — помеха; 2 из 3 закрыты → луки/арбалеты
  навесом 45°, пули — нет выстрела по этой цели; каждый боец перед выстрелом проверяет свой путь (земля — помеха, кроме
  0,1 м у цели). Флаг отряда «линия закрыта» (`1432860e0`): перекрыто ≥ round(min(M, N) × ratio), ratio 0,75 ваниль,
  1,0 мод `true_sight.pack`; на выбор выстрела не влияет.

## 4. Скорость на склоне — В (код), С (длина L)

```
143072eb8 (каждый тик, боец идёт сам, не по особому пути param_1[6] == 0, состояние +0x104 ∉ {2, 3}):
  dir = нормированная скорость (+0xe0/+0xe8); L = +0xa0 (С: радиус/длина шага тела)
  g = (высота_земли(pos + dir·L) − y) / L          → +0x244
  g > 0 (в гору) и нет strider:  k = 1 / (1 + g)
  g < 0 (под гору):              k = min(1,5; 1 − g)      (strider тоже)
  скорость = max(минимум 143072d80, скорость × k)
```
Примеры: g = 0,1 → ×0,91; 0,25 → ×0,80; 0,5 → ×0,67; 1 (45°) → ×0,5. Вниз: −0,1 → ×1,1; ≤ −0,5 → ×1,5.

## 5. Усталость на склоне — В

```
14308a720: r — прибавка за тик по занятию (шаг −1, бег +4, натиск +34, ...)
  g > 0,2: r = trunc(r × 150 / 100);  0,1 < g ≤ 0,2: r = trunc(r × 100 / 100);  0,05 < g ≤ 0,1: r = trunc(r × 50 / 100)
  (ключи _kv_fatigue gradient_very_steep / steep / shallow_movement_multiplier = 150 / 100 / 50; целые; strider — нет)
```
Пологий подъём 5–10 % **уменьшает** прибавку вдвое (бег +4 → +2, шаг −1 → 0), 10–20 % — как на ровном, > 20 % — ×1,5
(бег +6, шаг −1, натиск +51). Вниз и стоя — без изменений. Похоже на ошибку CA (задумывали +50/+100/+150 %), но код
читает именно так. Проверить пробой.

## 6. Мораль — В
`14301b828`: +10 (`ume_encouraged_on_the_hill`), если отряд не летает (С), враги в списке (120 м) есть, и y его точки

## 7. Высота земли — В (код), С (шаг сетки)
- `142f7c9ac`: регулярная сетка, узлы по 16 байт (первое float — высота), шаг +0x38, 1/шаг +0x3c, сдвиг +0x34;
  индекс = floor(x/шаг) + сдвиг, зажим краём; **билинейная** интерполяция 4 узлов.
- Шаг: по снятой сетке 1 м Кислева вторая разность вдоль X парная (узлы на чётных метрах) → **2 м** (С; одна карта).
- Боец на плоскости (стена, мост — `r8` ≠ 0) берёт высоту плоскости, а не земли.
- Lua `bm:get_terrain_height(x, z)` = max(`142f8f4bc`, земля). `142f8f4bc` — вторая сетка той же формы (Н: уровень воды).
- Lua-запросов линии видимости/огня нет (в таблице поля боя только `get_terrain_height`, `is_area_clear`,
  `ground_type`); у отряда есть `is_visible_to_alliance`, `missile_range`, `unit_in_range`.
